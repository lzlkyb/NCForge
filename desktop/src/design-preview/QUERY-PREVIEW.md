# 查询交互设计预览

入口：`http://127.0.0.1:1425/query-preview.html`

在 desktop 目录执行：`npx vite --host 127.0.0.1 --port 1425 --strictPort`。

复用真实应用外壳、Monaco SQL 编辑器、数据库工具条与结果网格，额外反馈样式仅在此预览入口加载。IPC 在浏览器内被模拟，不连接数据库、不调用原生窗口命令。独立端口隔离本地存储。

底部选择正常、极速、慢查询、空结果、失败场景，再点击真实执行按钮或 Ctrl+Enter。慢查询可停止。表格支持原组件的本地排序、筛选、列布局和单元格查看。结果数据为演示数据，SQL 不发送至数据库。

预览服务需保持运行；关闭运行 Vite 的终端或按 Ctrl+C 可停止。
