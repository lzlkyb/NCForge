## 真实桌面业务验收

使用独立测试标识的 Tauri release 程序、Rust 后端和 WebView2，业务调用没有替换为 mock。测试工程仅位于本轮缓存目录，不使用用户的数据库连接和生产数据。

首轮已通过：

- Java 草稿切页保留，真实保存到磁盘；6004 行文件只渲染 29 个可见编辑行，切页保留末尾滚动和编辑器实例。
- 标准模块目录索引 126 份 BMF；元数据图形、字段表与属性检查器联动，完成编辑、预览、保存、备份与校验恢复。
- 当前 BMF 整套生成实际写入 Java、Oracle SQL 和注册 JSON 共 3 个文件，0 失败；核对磁盘内容，逐文件选择和重复生成保护正常。
- 浅色、深色、玻璃材质、实时减少动效；原生 560×800 窗口无横向溢出，生成配置入口可用。
- 连续运行 600.157 秒，完成 24 轮切页、文件关闭与重新打开，原生最小化和恢复正常，无页面异常。

现场发现并修复三项：

1. 公共按钮在 idle 内容更新时测量宽度，引发反复强制排版；移除尺寸读取，使用原内容自然占位，保留 180ms 等待规则、即时防重和调用方宽度。
2. 生成输出目录误填为已有文件时仍显示已检查；保留路径白名单，并校验最近已存在的祖先必须为目录，预览与实际写入共用校验，未创建目录仍可正常使用。
3. 已检查的目录输入框失焦时重复检查，可能在按下与抬起鼠标之间禁用写入按钮，吞掉第一次操作；已检查或正在检查时跳过重复失焦检查，Enter 和“重新检查”仍按用户要求主动核对。

最终桌面复验已通过 7 项检查：文件及其下级路径拒绝、已检查目录后第一次全选、输入框失焦后的第一次写入确认、三类文件实际写入、原文件哈希保持、清单入口、窄窗口与实时外观切换。新目录生成 Java 924 字节、SQL 466 字节、注册 JSON 2281 字节，3 写入、0 失败；结果与窄窗口截图已重新拍摄。
