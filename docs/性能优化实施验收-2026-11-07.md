# 性能优化实施验收

本次按前后端性能审查的 11 项落实代码改动。未连接真实业务数据库，未运行安装包构建，未提交本批代码。

## 实施对应

| 审查项 | 落实 |
|---|---|
| 结果内存增长 | 单结果保守估算 16 MiB、最多 25,000 行；SQL 结果合计 64 MiB。截断保留 hasMore / 部分结果语义，提供主动释放查询结果入口，不提交或回滚事务。隐式结果集共享预算，首结果别名复用。脚本执行本身的 retained 引用同步受预算约束。 |
| 表结构同步大响应 | Java / Rust 驱动新增独立元数据游标 schemaBatch，每批最多 1,000 行；按表名与列名 keyset 续读，增量构建缓存。转换、构建与落盘在 spawn_blocking 内；全局单飞、总超时 300 秒，失败不替换旧缓存。Java 桥 jar 已重建。 |
| 大结果主线程筛选排序 | 达到 20,000 单元格且存在筛选/排序时，120ms 防抖后使用 Worker；分批传入 128 行，分批间让出主线程。旧 Worker 终止、过期消息丢弃，失败可重试。Intl.Collator 复用。 |
| 宽表渲染 | 行列共同虚拟化，冻结列保留；预计算列位置；选区使用逻辑区间，避免展开大集合。滚动仅在跨行/列桶或尺寸变化时更新，保留精确垂直位置用于密度切换。 |
| 深分页 | 默认非空主键排序的相邻页使用绑定参数 keyset，支持复合键、精准数值和反向读取。视图、自定义排序、随机跳页、NULL/不支持类型等继续安全回退旧分页。完整导出不带 seek 参数。 |
| 日志重复扫描 | 有界 32 文件 checkpoint；重复 tail 不再重复扫描已计数前缀，追加只计新增前缀，轮转/截断/常规重写校验失效。首次读取仍需建立行号索引。 |
| Monaco 首次成本 | 用显式贡献清单替代 editor.all；保留查找、差异、多光标、提示和编辑能力，去掉未使用的颜色选择器与实验编辑贡献；语言 tokenizer 仍按原有贡献机制懒加载。 |
| 空闲会话 | 一个应用级、60 秒、受监督且跳过错过节拍的回收任务；复用已有 idlePing、事务与使用状态保护，不为每连接创建定时器。 |
| 草稿持久化 | 仅 SQL 内容、持久化设置、标签结构或活动标签发生变化时触发；结果、运行状态与事务更新不再调度草稿存储。 |
| 空日志轮询 | 无变化保持快照/行引用；空读逐步从 500ms 退避到 4s，出现内容恢复 500ms，隐藏页仍停读。停止后的补拉和旧代响应保护保留。 |
| 复制链路 | 大小估算按时间片让出主线程；空列选项正确计算有效列数；Worker 每批 128 行，仅携带选中列与 SQL 键值，结束或错误后停止发送并释放 Worker。保留 5 MiB 剪贴板保护。 |

结果仍使用普通不可变行数组，避免破坏编辑、快照和导出消费者；追加复制已由行数/字节预算限定，不是全项目迁移到分块数组。预算是保守数据估算，不等于整个 WebView 的实际堆上限；表页、对比快照和打开的导出窗口也占用内存。

## 验证边界与环境

- 真实 Oracle 执行计划、远程网络延迟、数据字典批次查询耗时仍需在代表性环境实测；未声称实际 SQL 已加速某个百分比。
- 非空主键等值排序之外保持原查询语义，不盲目修改用户自定义 SQL 或增加索引。
- 已使用/带会话状态、运行中、事务不确定的会话不强制回收；安全保护优先于资源释放。
- 日志 checkpoint 针对追加式日志；首次建立精确行号仍需扫描前缀，不能宣称首次读取是常数时间。样本不是任意中间篡改的完整哈希。
- 完整 Rust 测试曾因正在运行的开发版锁住 `target/debug/nc-forge.exe` 而无法覆盖可执行文件，随后使用库测试和全目标 Clippy 验证，没有中断运行会话。
- 工作区另有影子目录接口改动；三个旧 live 集成测试仅补充新的参数以保持编译兼容，相关业务逻辑未在本任务重写。
- 所有重任务串行；Rust 限 1–3 编译任务、2 测试线程，临时目录经项目 wrapper 收尾。可用内存为分段采样，非连续峰值监控；前端验证期间采样最低约 2.4 GiB。
- 既有 `target/debug/incremental` 约 5.56 GiB，整体 debug 约 12 GiB，超过项目磁盘预算。只针对已核验增量缓存路径的清理被自动审批策略阻止，未绕过或删除；该环境告警保留。
