## 体验方法

- 底部「柔光玻璃 / 经典」按钮切换界面材质；「深浅切换」切换主题。两种材质共用圆角、连续工作面与布局，经典浮层使用实底，玻璃浮层使用半透明模糊。设置页内切换材质时，体验按钮同步更新。
- 「元数据」查看连续资源栏、单层搜索框与居中空状态；可重新索引、调整资源栏宽度，窄窗口可打开资源抽屉。也可使用 `http://127.0.0.1:1436/?page=meta` 直接进入。
- 「设置」查看圆角分组、分段选择、侧栏和搜索；实际开关仍可使用。
- 「命令面板」查看半透明浮层，可以搜索命令、用上下键选择、按 Esc 关闭。
- 「字段补全」显示实际字段候选；「查询辅助」从表名显示关联查询、主表条件查询、单号查询、缺失明细和汇总建议。
- 「关联检查」显示 LEFT JOIN 筛选范围的快速修复菜单，可选择修复；这两个演示入口会替换当前示例 SQL。
- SQL 工具栏的「…」打开真实工具菜单；标签页可切换、关闭、拖动。
- 「收起」隐藏体验工具，保留完整工作台；底部按钮可恢复。

初始 SQL 使用 `WHERE a.vbillcode = '';`。结果区展示上次示例查询的 8 行数据；直接执行空单号条件会返回空结果。可在引号内填写 `ASSCG2026110800000005` 后手工执行，返回 8 行示例数据。没有额外参数输入框。

## 视觉范围

柔光玻璃采用中性浅灰和石墨深色，经典沿用既有配色，强调色沿用青绿色。两种材质的标题栏、侧栏与标签栏形成连续背景；文档标签为胶囊形状；设置使用圆角分组。菜单、命令面板、字段建议、悬停提示与快速修复菜单共用圆角和层次阴影，玻璃为半透明模糊，经典为实底。编辑器、表格、日志和长连接表单维持实底阅读面。

整体外壳已扩大到用户标注的完整工作区：资源栏、文档、底部面板和状态栏由同一个 14px 圆角外壳裁切，只保留一层整体轻微阴影；顶部标题栏和左侧导航位于外壳之外。代码、版本控制、数据库、元数据、日志和设置共用此结构。内部资源栏与主区不再带独立圆角或阴影，资源栏通过轻微底色与正文区分；SQL、结果、工具栏和结果页脚共用同一实底，删除内部灰缝及重复框线。窗口圆角保留 16px，工作区外围保留 4–6px 小间距，窄窗口外围 3px；覆盖式资源抽屉保留 12px 圆角与浮层阴影。

文档和结果标签用柔和填充表示选中；表格保留表头底色、轻微交替行底色与淡横线，选中范围、活动单元格、错误和拖放反馈仍清晰可见。设置分组保留圆角实底，移除逐行横线及分组阴影。侧栏和结果区分隔提示在静止时隐藏，悬停或键盘聚焦时出现；原有拖动与键盘调整仍有效。窄窗口侧栏作为覆盖面板保留实底与浮层阴影。

保留 40px 标题栏、60px 导航栏、36px 标签栏、40px SQL 工具栏、26px 表格行和现有字号。文档标签在原有 36px 标签栏内呈现为 30px 胶囊。1910×915、1024×768 和 560×800 窗口无整页横向溢出。
