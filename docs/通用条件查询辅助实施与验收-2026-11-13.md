# 通用条件查询辅助实施与验收

日期：2026-11-13。对应用户确认的“关联查询 + 任意条件字段 + SQL 内手工填写值”方案。

## 使用方式

1. 在 SQL 编辑器的新语句位置输入表名或已加载的 NC 中文表名。
2. 选择“主表条件查询”，或“主表名 · 关联查询 关联表名”。生成 SQL 后，光标停在 `WHERE` 后，并自动显示字段补全列表。
3. 输入字段英文名或中文说明，例如“物料”“组织”“数量”。候选显示字段、别名、来源表和填写方式。
4. 选择“等于”后直接填写值：文本光标在单引号内，数值光标在等号后，日期使用实际字段类型对应的表达式。
5. 输入 `AND` / `OR` 后可继续选择字段；也可以在 `ON` 中追加条件。条件始终留在用户正在编辑的位置。

精确输入字段名或中文说明时，会列出该字段适用的其他条件；已手工输入字段后，按空格或 `Ctrl+空格` 可选择运算符。例如：

```sql
SELECT a.*, b.*
FROM po_order a
LEFT JOIN po_order_b b
    ON a.pk_order = b.pk_order
WHERE b.pk_material = 'MAT1'
  AND b.nnum > 100
  AND a.pk_org = 'ORG1';
```

上述值为演示数据。表名、可选字段和关联键来自当前连接的元数据。条件选择不会改变 `SELECT a.*, b.*` 的输出。

## 支持的条件

| 字段类型 | 条件及填写方式 |
| --- | --- |
| 文本 | 等于、不等于、包含文本（LIKE）、值列表（IN）、空值判断；值在引号中填写 |
| 数值 | 等于、不等于、大于、小于、包含端点的 BETWEEN、IN、空值判断；值不加引号 |
| 日期、时间 | 等于及大小比较、含起点不含终点的时间范围、IN、空值判断；按 SQL 方言生成日期表达式 |
| 布尔 | 等于、不等于、IN、空值判断；直接填写 SQL 值 |
| 未知类型、LOB 等 | 保留普通字段补全，提供空值判断，不猜测不受支持的比较方式 |

日期范围和 IN 提供两个填写位置，按 `Tab` 切到下一项。NC 中 `CHAR` / `VARCHAR2` 类型的日期字段仍按文本处理。SQL Server 的 `TIMESTAMP` 按版本字段处理，不生成日期条件；PostgreSQL 带时区和不带时区的时间类型分别处理。

存在 `vbillcode` 时保留原有单号快捷入口，接受后直接在空引号内填写单号。组织快捷条件也直接在 SQL 中填写，不再生成 `:pk_org` 参数弹窗。

设置中的“SQL 智能补全 → 查询与条件模板”控制整句模板及条件片段；关闭后保留普通表名与字段补全。

## 范围与编辑边界

- 完整关联模板沿用已连接 Oracle 的当前 schema 元数据路径，根据数据库外键或 NC 类引用确认关系，不写死具体单据。没有 `vbillcode` 也能生成通用模板。
- 多个关联表分别列候选，每条查询只连一个关联表。字段和关系读取沿用缓存、并发门控、时间预算及过期检查。
- 无法确认关系时可使用主表条件查询；没有可读字段时保留普通查询模板。
- `SELECT`、函数参数、算术表达式、BETWEEN 的数值位置和已有比较式中只补字段，不追加完整条件。
- 检查布尔分组右括号外的现有运算。直接 `NOT` 下隐藏会追加 AND 的日期范围及整关联条件；显式 `NOT (...)` 内可使用范围。
- 日期范围两端均保留字段限定名。`ON` 中只提供当前已经出现的表，不引用后面的 JOIN。
- 选择模板只编辑 SQL，执行仍由用户通过原有执行按钮或 `Ctrl+Enter` 触发。
