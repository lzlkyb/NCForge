## 3. 运行隔离与取消

- 编译产物、运行参数文件、测试 XML 和覆盖率写入工作台配置目录 `java-runs/<run-id>/`；不修改 NCHOME，不执行 NC 部署。
- 运行前要求保存打开文件的修改；目标限制当前工程 Java 文件或模块目录，额外类路径限制工程或 NC 目录。
- JUnit / JaCoCo 首次使用从官方 Maven 仓库按需获取，固定 SHA256 校验成功后执行；离线且没有缓存时展示下载错误。
- Java 任务单飞。编译限 120 秒、运行限 30 分钟、报告限 120 秒；超时或取消终止子进程。
- PID 在编译、运行、报告和诊断阶段登记，退出时同步清理；登记在返回/异常路径自动移除。
- Windows 创建暂停进程，加入持有句柄的专属 Job 后才恢复执行；取消、父进程退出或作用域结束都清理该 Job，父PID退出/复用不影响后代清理。Unix为运行器创建专用进程组，取消和父进程退出时终止该组；本机Windows未实际验证Unix路径，主动脱离组的daemon仍有边界。
- 切工程先取消当前main/JUnit/已附加本地调试任务，等待运行及附加流程结束，再切换工作区；切换过程中拒绝新运行。输出管道有绝对2秒收尾上限，总超时或不完整输出不能因父进程返回0而判定通过。
- 指定Java文件优先按其真实完整声明编译；同文件的其他顶层类、嵌套类和不同包的同名文件不会按basename混选，未找到源码明确拒绝执行旧输出。失败栈保留真实文件名及行号，支持$方法名、中文/空格/括号源码文件名。
- 后端输出限 20000 行且单条读取限 64 KiB，前端保留最近 1500 行。
- 机器可读结果也有限额：最多 1000 条类汇总与 1000 个失败详情，超出明确标为不完整且不判定全部通过；完整测试结果仍保存在官方 XML 中。
- 运行缓存保留最近 12 次。只清理由本运行器创建且带专用标记、解析后父目录匹配的目录，不清理一般 TEMP 或其他数据。
- 覆盖率类目录扫描限 100000 项 / 512 MiB，超出明确报错并保留测试结果。

## 4. 适用边界

1. 独立 Java / JUnit 运行不会自动构造 NC 容器、登录上下文、数据源或远程服务；依赖这些环境的业务测试需要工程已有初始化方式和正确类路径。
2. 工程运行与覆盖率使用当前配置的 Java 8；不把 JFR 视为所有 Java 8 都可用。当前本机 JDK8 实测返回 `Java Flight Recorder not enabled. Use VM.unlock_commercial_features to enable.`，未自动启用商业功能；目标 JVM 支持时可开始/停止并保存记录。
3. 覆盖率报告范围是本次私有编译类及工程输出类；不把所有 NC 库 JAR 当作业务覆盖范围。HTML 在系统浏览器打开。
4. 测试模块发现是源码候选发现，识别 JUnit 注解 / TestCase；测试的最终执行和统计以官方引擎结果为准。
5. 源码失败定位按完整类名及真实源码行处理。没有源码匹配时提示使用顶部搜索，不把反编译行号当作原始源码行号。
6. JVM 工具输出与 JFR 文件已提供；内置火焰图、CPU/堆录制分析器及线程死锁可视化没有在本批新增。内存对象统计可能短暂暂停目标 JVM，界面已提示。
