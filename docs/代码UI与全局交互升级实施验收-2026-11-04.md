## 已交付

| 范围 | 升级后的行为 |
| --- | --- |
| 文件与 jar 类读取 | 超过 300ms 显示局部读取提示与运行任务，保留原编辑器。同文件请求合并；Windows 大小写路径复用标签。旧工程、旧预览与旧跳转结果不会抢当前激活项。类源码读取/反编译说明实际阶段，失败可在代码区域重新读取。 |
| 保存与重载 | 从保存前格式化开始同步防重入；格式化失败仍可保存并注明原因。写盘记录提交时版本，继续输入仍保留未保存状态。重载期间新增编辑不会被慢结果覆盖；工程切走再切回同路径也使旧请求失效。切工程/安装前预检等待已有文件写入收尾。 |
| 工程与结构 | 文件树、空工程引导、服务配置共用切换任务锁，守卫阶段也反馈等待。工程切换与代码智能索引就绪分别说明。结构面板区分加载、错误、空结果与语言服务未就绪，可重试；Escape 恢复触发器焦点。 |
| 点击、键盘与动效 | 标签关闭按钮 Enter/Space 不被父标签拦截，方向键漫游保留；组合输入不会误提交。常用图标补 pressed/focus/selected 反馈；结构与任务面板按既有动效进退场，编辑器不重建、终端画布不移动。 |
| 窄屏状态栏 | 所有状态与按钮保持单行。650px 以下隐藏编码、行尾、光标与工程关联快捷入口，代码智能长文本省略；保留文件路径、任务、保存状态、服务入口、面板开关及警告/待提交事务。 |
| 全局运行任务 | 顶栏与状态栏入口互斥、ID 唯一。显示实际阶段、耗时、进度、失败与结束结果；关闭面板不停止任务。保留最近 30 条结束记录，清理不删除活动任务。来源操作定位原页面、文件、数据库标签或服务/调试面板。支持停止的操作等待真实后端返回，不把停止请求已发送当成已取消。 |
| 编译与任务链 | 手动编译、组合任务及菜单等待状态覆盖整条任务；失败跳过后续步骤。补丁步骤说明只打开打包页；重启步骤说明请求已接受，端口就绪由独立服务任务确认。自动编译保持既有局部反馈，避免自动任务刷屏。 |
| SVN、补丁、工程检查 | SVN 读取/扫描/更新/提交/撤销/冲突处理/维护、补丁扫描/生成/恢复、元数据投送、UPM 与产物检查接入任务。补丁使用真实条目数；投送、备份清理和检查结果说明失败或部分完成。 |
| 搜索、日志与语言动作 | 正式搜索/替换、日志原文检索/追踪/主动刷新、重构/组织导入/代码生成/层级查询和手动语言服务启动有任务反馈。刷新保留旧结果；截断、范围回退与部分失败明确说明。 |
| 数据库与 NC 字典 | 连接、配置、SQL、计划、续取、独立会话、事务、表查询/写回、对象元数据/关系、CSV 导入、流式导出、按值反查、字典及操作员动作补齐反馈。重复操作受保护，取消与部分写入按真实结果显示；导入结果窗口保留失败详情。SQL/绑定值/口令/原始数据库异常不进入默认任务摘要。 |
| 服务、调试、设置与下载更新 | 服务启动请求返回后跨页观察监听端口；调试控制失败可恢复暂停上下文。设置路径、数值、内存、端口与配置迁移补齐同步锁、IME、spinner 和失败保留草稿。更新与组件置备复用实际事件和字节进度；安装任务明确最终版本须重启后确认。 |
