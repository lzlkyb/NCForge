# 工作台布局对照实施与验收

日期：2026-10-30。基准：`design/workbench-20261029` 中已经确认的交互设计稿。

## 实施范围

| 区域 | 实际实现 |
| --- | --- |
| 应用壳体 | 共用导航、标题栏、单一工具栏、侧栏、中央标签区和底部状态栏 |
| 文件 | 源码编辑器常驻；共享侧栏默认 255px，可收起和调整宽度 |
| 搜索 | 搜索表单与结果放在共享侧栏，点击真实结果在中央打开源码 |
| SVN | 变更列表放在共享侧栏，差异和提交表单在中央；保留源码切换入口 |
| 文件树 SVN | 使用真实状态结果，显示文件状态和目录变更计数，支持手动刷新 |
| 服务 | 控制入口在工具栏，日志与配置在底部；上方源码仍可见，配置可展开 |
| 补丁 | 清单在共享侧栏，预览与输出在中央；移除重复生成入口 |
| 数据库 | 已知表清单在共享侧栏，SQL 与结果在中央，保持现有只读限制 |
| 设置 | 分类在共享侧栏，选项在中央，不再额外嵌套一列导航 |
| 快捷键 | 默认 Eclipse，可切换 IDEA；已接入的操作显示实际键位，未提供能力明确说明 |

工具首次打开后保留其输入和结果；非活动工具的挂载内容隐藏，避免跨模块重复显示。源码编辑器在切换中央工具文档时保持同一实例。

## 验证结果

- 30 个前端测试文件、267 个测试通过。
- TypeScript、ESLint、组件大小检查通过。
- `npm run vite:build` 成功；仍有 Monaco 大体积代码块提示。
- 实际 Tauri 开发窗口验证：文件、搜索、SVN、服务、补丁、数据库、设置及浅色/深色。
- 用现有工程完成真实内容搜索并打开 Java 源码，确认搜索侧栏和编辑器同时存在。
- 独立布局复核发现服务面板较矮时可能裁切内容，已增加滚动与日志最小高度，复核通过该问题。

## 收尾修复（复审后）

复审在提交前发现 6 项遗留问题，已全部处理：

| 问题 | 处理 |
| --- | --- |
| SVN 变更列表沿用双栏时代的 `width:322px`，停靠进 255px 共享侧栏后右侧被裁约 67px | `.wb-sidebar-host .vc-chg` 改为 `width:100%; min-width:0; flex:1 1 auto`，并去掉与拖动分隔条重复的右边框；选择器优先级高于 `.vc-chg` 自身及其窄屏覆盖，无需关心样式表加载顺序 |
| 全工程搜索在顶栏写 `Ctrl+K`、设置页写 `Ctrl+H` / `Ctrl+Shift+F`，三个键都能进搜索页却各说一套 | 收敛到 `lib/keymap.ts` 的 `WORKSPACE_SEARCH_CHAR` / `WORKSPACE_SEARCH_KEY` / `workspaceSearchLabel`，顶栏与设置页同源；`keymap.test.ts` 断言标签里出现的方案键必须被 `isWorkspaceSearch` 认下 |
| 数据库对象侧栏把一万多张表一次铺成按钮 | 增加表名筛选框，列表改为容器内滚动，只渲染前 300 条并提示剩余数量 |
| 「哪些工具有侧栏 / 有中央文档 / 默认打开文档」三份清单各写一遍，`svn` 缺席默认列表却无说明 | 收成 `TOOLBAR_TITLE_TABS` / `SIDE_TOOLS` / `DOCUMENT_TOOLS` / `DOCUMENT_DEFAULT_OPEN` 四个常量，并注明 `svn` 默认停在源码是有意为之 |
| `workbench-layout.css` 中三处声明被后续规则整段覆盖（搜索栏 flex 布局、日志最小高度、`display:contents` 重复定义） | 合并到唯一定义处，删除死声明 |
| 本轮编辑把 19 个文件写成 CRLF（连同 `HeapField.test.tsx`、`utils.ts` 两处既有污染共 21 个），与 `.gitattributes` 的 `eol=lf` 不符 | 全部转回 LF；`git ls-files --eol` 已无 `w/crlf` / `w/mixed` |

验证：组件体量门禁、`tsc --noEmit`、`eslint .`、`vitest run`（30 个文件 / 268 个测试）、`vite build` 全通过。

**未做视觉复核**：dev 窗口被 Eclipse、CC Bridge、微信占满，`SetWindowPos(HWND_TOPMOST)` 与 `SetForegroundWindow` 均返回成功但窗口仍不绘制（真隐藏态，见 skill `desktop-window-screenshot` 坑 7），本轮不再抢占前台。改动为纯前端与 CSS，建议在窗口前手动确认三处：SVN 变更列表右侧不再截断、数据库侧栏筛选框可输入、未打开工程时不再留空标签栏。
