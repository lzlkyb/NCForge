## 实现边界

- `toolReturn.ts` 在应用导航入口同步记录来源，避免连续事件读取上一帧状态；返回只恢复面板、展开与侧栏开合，不回滚用户拖动后的尺寸。
- 工程上下文通过工作台原有槽位机制渲染；服务仍使用现有状态查询和启停命令，日志跳源码仍通过真实类型定位。
- 工具文档页让出底部面板，服务展开态不会遮住数据库或元数据正文。
- 沿用现有主题、字体、Monaco、菜单、表格和对话框。新增样式使用生产 token。
- 本次未修改 Rust 命令、版本号或安装包，也未提交代码。
