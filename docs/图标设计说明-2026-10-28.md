# NCForge 图标设计

日期：2026-10-28。交付：三款可编辑图标、配色变体、交互预览与应用素材包。

## 设计依据

产品名称与用途以 `desktop/src/lib/about.ts` 和最新多期规划为准：NCForge 是 NC65 / NCC 二开的轻量桌面工作台，主要操作是写代码、编译、启服务。现有图标已经采用铁砧意象，因此主方案延续 Forge 的锻造含义，把形状收敛为更紧凑的单色符号。

参考观察：

- **Codex**：查看了本机 Codex Windows 安装包中的 OpenAI 几何结扣图标，并参考 [Codex 应用页面](https://developers.openai.com/codex/app/)。提炼的是单色、高对比、清晰负形与紧凑轮廓。
- **Claude Code**：查看了 [产品页面](https://claude.com/product/claude-code)、其中的终端示意图及 Claude 星芒标记。提炼的是暖色、克制的配色和终端视觉的亲和力。
- 这三款图标的几何路径均独立绘制，围绕 NCForge 的锻造含义及名称构成。

## 三个方向

| 方案 | 图形构成 | 特点与取舍 |
| --- | --- | --- |
| **A · 铸台（推荐）** | 工作面、斜向支柱、稳定底座，组成抽象铁砧 | Forge 含义最直接，保留现有品牌线索；更偏工具感，不以首字母为记忆点 |
| B · 榫接 | 两段几何构件组成 N，中间一道斜切口 | NC 名称识别更直接；微小尺寸时切口的辨识弱于完整轮廓 |
| C · 光标 | 等粗矩形 F 与独立方块 | 终端属性更明确；锻造与 NC 的含义弱于另外两款 |

推荐 A 的炭黑版作为应用图标。中性配色能和当前界面的靛蓝主色共存；赤陶版提供更温暖的独立视觉方向。

## 配色与尺寸

| 配色 | 底色 | 符号 |
| --- | --- | --- |
| 炭黑 | `#232522` | `#F3F0E8` |
| 暖白 | `#F3F0E8` | `#232522` |
| 赤陶 | `#B86346` | `#FFF8EF` |

- 矢量画布为 512 × 512；底板位于 `(16, 16)`，宽高 480，圆角半径 112。外角透明。
- 图标用实色路径构成，无字体、外链、滤镜或脚本依赖。
- PNG 母版为 1024 × 1024。炭黑版另附 16、20、24、32、40、48、64、128、256 像素文件。
- ICO 包含 16、20、24、32、40、48、64、128、256 像素帧；ICNS 提供 macOS 图标资源。
- 另附透明背景的墨黑、暖白符号，以及 16、24、32 像素的托盘版本。

## 查看与使用

- 交互预览：`design/应用图标-2026-10-28.html`。可直接在浏览器打开，切换三个方案和三种配色，查看实际尺寸和深浅背景。
- 总览图：`design/应用图标-2026-10-28/图标方案总览.png`。
- 完整素材包：`design/应用图标-2026-10-28/图标素材包.zip`。
- 每个方案目录中的 `图标.svg` 是炭黑版矢量源；`图标-暖白.svg`、`图标-赤陶.svg` 为配色变体。
- 每个方案均附 `icon.png`、`icon.ico`、`icon.icns`、`32x32.png`、`128x128.png`、`128x128@2x.png`，可用于项目现有的 Tauri 图标配置。

当前交付为设计素材。应用接入时，前端使用 `desktop/public/icon.png`，桌面与安装程序图标使用 `desktop/src-tauri/icons/`；安装器侧栏与横幅属于另两张位图，需要按最终选择的方案同步设计。

`design/` 是项目已有规则中忽略的本地设计目录。如需长期保存，请保留素材包或在正式接入时把选定源图归入项目资产目录。
