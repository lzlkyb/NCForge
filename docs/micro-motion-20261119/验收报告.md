# NCForge 微动画升级验收

日期：2026-11-19。保持现有工作台布局、配色及业务流程，动效用于确认操作和解释位置变化。

## 本次覆盖

| 场景 | 最终行为 |
|---|---|
| 左侧主导航 | 单个选中底板连续移动；远距离切换采用局部淡入；快速切换合并到一帧，反向操作从当前视觉位置开始 |
| 代码、数据库、元数据标签 | 单个选中下划线；代码和数据库关闭标签后，相邻标签用位移补位；不重建编辑器 |
| 文件树 | 展开箭头旋转，小分支淡入；定位完成后短暂描边确认，不抢编辑焦点；大分支不批量播放动画 |
| 页面切换 | 代码正文、SQL 编辑器与结果区立即呈现；只在所到标签上给出轻微反馈 |
| 按钮、菜单、提示 | 统一短按压反馈；自定义上下文菜单与提示轻微进场；保存状态局部确认 |
| 弹窗 | 文字原尺寸轻位移进退场；关闭立即归还焦点并停止接收交互；快速重开保留同一个尚未卸载的输入节点 |
| 查询、回放、传输 | 已知进度用缩放绘制；未知进度仍显示等待状态；查询成功提示局部出现，结果表格不整块闪动 |
| 无障碍与后台 | 尊重系统和软件内“减少动效”；后台与非活动页面暂停循环视觉；高对比模式恢复系统选中样式 |

常用反馈约 100ms，按压 70ms，进场 180ms、退场 140ms，复用现有动效令牌。没有新增动画库。正文不等待动画结束。

## 性能结果

在同机 Edge 无头浏览器运行生产前端资源，采用内存 IPC 固定数据：3000 个文件节点、30 个已打开标签、每份代码 1602 行。测试期间不并行执行本任务的构建或测试。

P95 表示 95% 的采样不超过该耗时，包含目标状态提交至下一帧呈现确认；不要求局部装饰动画播放结束。

| 操作 | 样本 | 升级前 P95 | 升级后 P95 | 目标 |
|---|---:|---:|---:|---:|
| 已缓存文件切换 | 90 | 61.2ms | 61.6ms | ≤100ms |
| 左侧页面切换 | 60 | 107.8ms | 117.6ms | ≤150ms |
| 持续输入回显，20键/秒 | 29 | 34.8ms | 30.4ms | ≤50ms |
| 菜单首次呈现 | 10 | 36.6ms | 34.2ms | ≤100ms |

页面切换并未变得更快：P95 增加 9.8ms，仍在目标内。第一次升级后测得 133ms，合并标记测量后降为 117.6ms。文件切换没有观测到 >50ms 长任务；60 次页面切换仍记录 11 个长任务（升级前 2 个），主要集中在恢复代码工作区，后续性能优化仍有空间。单机单轮结果不代表所有工程和设备上的帧率保证。

60 次页面切换前后，DOM 节点 34921→34921、监听器 5440→5440、文档数 2→2；强制回收后堆约 50.8→52.2MB。缓存文件切换没有新增文件读取。

30 个标签、原编辑器 DOM、SQL 草稿、代码草稿及视图、撤销与撤销至已保存状态均通过。浏览器运行错误为空。

原始数据：[升级前](performance/before.json)、[升级后](performance/after.json)。性能脚本已加入上述 P95 目标及 DOM/监听器稳定性断言。

## 验证范围

- 全量前端测试：600 个文件、4440 项通过。随后对最终的测量合并修改运行 4 个文件、14 项相关测试，全部通过，其中新增同一帧合并和卸载取消回归。
- 实际浏览器动效检查：15 项通过，覆盖进退场、快速反向操作、标签补位、草稿、键盘与焦点、主题、窄窗口、减少动效及后台暂停。
- 生产前端页面切换回归通过：6 页首次加载占位范围、18 次热切换、减少动效与状态保留检查无运行错误；没有启用整页 View Transition。独立记录见 [页面切换数据](page-switch/after.json)。
- TypeScript、变更组件 ESLint、组件体量、设计令牌与 UI 约定检查通过；生产前端构建通过。
- 新增动效表面设计扫描未输出问题。保留现有设计身份与交互语义。

## 交付边界

本次完成源码及生产前端构建，没有替换已安装的 NCForge，也未发布安装包。浏览器验收使用真实前端组件和内存模拟 IPC，不包含真实 NC 服务、数据库或原生窗口的端到端性能结论。
