### 01. 搜索结果缺少列表虚拟化

- [ ] 完成修复并通过最终验收
- **影响等级及证据：** 高 A
- **所在位置与模块：** `desktop/src/components/search/SearchResults.tsx`、`ResultFile.tsx`、`SearchResultViewport.tsx`，搜索渲染
- **原始问题及判断依据：** groups、工程分组、展开命中的 hits 均全量 map 创建组件；Viewport 负责容器移动，并非列表虚拟化。大量命中时 DOM、事件闭包、高亮节点和 React 更新成本随全部结果增长，选中一条也会更新父层
- **轻量化目标符合情况：** 大结果场景不符合
- **优化方向与验收点：** 文件组/命中统一虚拟列表，稳定行键；把选中状态更新约束到可见行。以万级命中测 DOM 数、长任务与键盘响应
- **当前进展：** 已实现统一虚拟行及键盘定位；万级命中 DOM 有界专项测试通过。真实 WebView 长任务与输入延迟待实测。

### 02. 搜索内容包缺少严格单包内存上限

- [ ] 完成修复并通过最终验收
- **影响等级及证据：** 高 A
- **所在位置与模块：** `desktop/src-tauri/src/content_pack.rs::Pack::open/insert_pack/current_for`，搜索缓存
- **原始问题及判断依据：** 整份 pack.bin 通过 fs::read 常驻 Vec；320MB 预算只淘汰其他根，单个包超限明确保留。大工作区没有严格内存硬顶

- **优化方向与验收点：** 单包准入预算、映射或分块读取；超限可降级。验证单包超过预算时的峰值与可用性
- **当前进展：** 实际文件长度与索引长度匹配校验、单包准入及限长读取；超限回落磁盘。边界测试与峰值验收见本轮记录。
