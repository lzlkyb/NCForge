## 收尾修复与审查

使用自定义 PowerShell `code-review` 命令执行数据库范围的 `git diff --check` 与差异检查，并人工检查新增前端模块、两种驱动及后端策略注册和执行路径。没有创建提交或 PR。

- 日期/时间主键的冲突回读与关联查询使用显式时间转换；高精度数值使用真实数值绑定，避免依赖会话 NLS 设置或 JavaScript 浮点精度。
- 已关闭的来源标签可重新打开原表；页内路径及关联弹窗的返回入口使用相同行为，并提示原标签已关闭。
- NC 字典开始读取前即失效旧游标续取状态，关闭弹窗不会漏掉这一步。
- 只读切换持有连接级写锁，验证所有会话事务；未知状态或未提交写入会拒绝切换。失败时恢复已触及的会话，完整成功后发布策略。
- 快照使用实际读取时的 SQL/页码；查询期间保留旧数据时，不把新查询页码标到旧结果上。
- 未打开工程时仍显示数据库文档标签，可切换、关闭表和 SQL 标签。
- 主题截图等待 ViewTransition 完成后采集；没有为了截图修改产品主题实现。
- NC 枚举字段从已验证的结构白名单选择；有 DR 字段时排除已删除的定义和值。

## 真实库验收边界

本轮未连接真实 Oracle/NC 业务数据库，未执行业务数据修改。实现及本地模拟验收完成不代表真实库兼容验收完成。还需使用已授权测试库确认：

1. 两种驱动在目标 Oracle 版本下的只读事务、提交/回滚后重建、多个独立槽和临时会话的一致性；已有写入时切换必须拒绝，不能隐式丢弃事务。
2. 两条真实会话的并发写回、部分成功后的事务处理、NULL、长 CLOB、DATE/TIMESTAMP 及 38 位 NUMBER；不支持的 RAW/BLOB/带时区时间字段不会开放表格编辑。
3. 目标 NC 版本的 MD 表结构、实体/引用/枚举映射及账号权限；未支持的元数据结构保留普通查询并展示原因，不能伪造关联。
4. 大型对象清单、长文本与大量结果的性能。当前对象查找只展示前 80 个匹配项，关系清单有读取上限；快照对比只覆盖两份已读取的数据。

只读查询模式使用后端语句约束和 Oracle 只读事务。它不改变账号授权；能调用带自治事务的数据库函数时，最终写入限制仍需由数据库账号权限保证。快照仅在内存保存；筛选和列布局按连接/表保存在本机。第一版未包含批量粘贴写入及跨库结构/DDL 对比，这两项原方案已明确留作后续。
