设置中心源码升级已落地。相关回归用例合计 120 项通过，前端生产构建和体积预算通过；浏览器完成 132 组页面布局检查、4 组弹框布局检查，保留 46 张实际页面截图。页面数据来自隔离的 Tauri IPC 验收示例。

## 分类与操作流程

| 分组 | 页面 |
| --- | --- |
| 使用偏好 | 外观与启动、编辑器、SQL 格式化、快捷键 |
| NC 开发 | NC 安装与检测、代码智能、编译与热替换、任务流程 |
| 维护 | 软件与组件、配置迁移、关于与支持 |

旧分类名称继续通过别名进入对应页面；具体设置通过稳定 ID 定位。自动编译从任务页移入“编译与热替换”，编辑器保留直达入口。

- 搜索与分类入口固定在正文顶部。定位后可以返回搜索结果，保留关键词和滚动位置；窄窗口选择分类后关闭抽屉并把焦点交给正文。
- 文本和数值先形成草稿，Enter 或按钮保存，Esc 还原，失焦只校验。写入失败保留错误与重试入口，即使当前会话已经应用同一数值也不会误报成功。
- NC 目录统一为选择、检测、核对、保存。浏览与扫描候选不直接写配置；运行中更换目录需确认，下次启动服务生效。配置目录与运行目录分别显示，完整路径可复制。
- 任务支持新建、编辑、编号排序、添加和移除步骤。保存与执行分开；草稿按工作区保留，替换有修改的草稿需要确认。
- 编辑器预览跟随有效草稿；恢复默认会清除字段和预览草稿。SQL 示例使用现有格式化库，方言优先从当前连接的实际地址推断。
- 快捷键冲突留在目标行，并能定位冲突命令；离开页面释放按键采集。恢复失败保留原绑定。
- 构建选项提供保存反馈和重试。热替换区分未知、代理准备中、已就绪及待推送状态；状态未知不显示“没有待推送的类”，代理就绪后才能推送。
- 软件更新与运行组件分区展示；保留单组件下载和重试，将全部重新下载放到维护区。迁移明确导出范围，导入前展示本机路径与待导入路径，支持只读检测，失败保留预览。

## 复现与验证边界

浏览器验收脚本已注册为 `desktop/package.json` 的 `test:settings-ui`。在独立 Vite 预览运行时，从 `D:/AItool/winapp/nc-workbench/desktop` 执行：

```powershell
npm run test:settings-ui
```

默认预览地址为 `http://127.0.0.1:1421`；可用 `SETTINGS_PREVIEW_URL` 指定已有的独立预览地址。脚本挂载正式前端，启动前隔离全部 IPC、文件输入和剪贴板。外围工作台未配置的后台读取会被拒绝并记录在 `unknown` 中。

本轮没有操作真实 NC 安装、运行服务、数据库或本机配置迁移。真实系统目录选择器以及 Windows 125%、150% 系统缩放未做原生窗口验证；浏览器窗口宽度与舒适密度检查不能替代系统缩放验证。未修改 Rust 后端，本轮没有执行 Rust 构建或测试。

测试采用单进程 Vitest、无头 Edge，重任务串行执行；本轮可用内存采样约 2.4–5.4 GiB，低值出现在检查运行期间。完成后已结束本次启动的 Vite 预览。工作区原有并行修改保留，未自动提交、发版或修改版本号。
