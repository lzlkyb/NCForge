| 范围 | 最终行为 |

| 审查队列 | 按当前可见筛选、排序和展开状态寻找下一个未审文件；末尾明确提示完成。标记失败保留当前项，同帧重复点击受保护。 |
| 差异阅读 | 自动单/双栏、忽略首尾空白、换行与字号偏好；显示真实新增/删除行统计和差异块位置。区分读取、计算中、无差异和可导航状态，首末边界禁用。删除文件仍显示 BASE 内容。 |
| 编辑器生命周期 | 阅读选项更新保留 Monaco 实例；切源恢复滚动和定位。通过公开 createViewModel/waitForDiff 持有在途计算，界面立即切走，计算结束后释放模型，修复未处理 Canceled 异常。没有全局过滤错误或修改 Monaco 依赖。 |
| 提交草稿 | 说明、选择和结果未知状态按工作副本隔离。首次扫描默认全选可提交文件，后续刷新不会悄悄加入新文件；冲突项排除。成功只移除本次实际提交项。 |
| 提交预检与结果 | 等待已有保存，仅确认所选文件的未保存编辑；保存后重新核对文件范围与状态。IME防误提交，共享写锁覆盖预检至刷新收尾。服务器确认 rN 与扫描失败分别提示；网络响应丢失保留待确认状态，引导查看历史，确认前阻止重试。 |
| 历史 | 当前路径、模块、工作副本范围；按已加载记录筛选说明、作者和日期。选择 revision 查看真实改动路径、完整说明及固定版本前后正文，处理新增、删除和复制来源。可复制版本号、路径。 |
| 准确逐行追溯 | 正文、作者、行号和归属来自同一固定 revision，不再混入工作副本正文。支持作者筛选，点击版本进入对应提交。 |
| 冲突处理 | 展示实际 mine/base/theirs 内容、文件名与版本号，预览和选作最终版本不会立即写入。可备份后采用选中版本，或检查冲突标记后保留已保存的手工合并结果。树、属性、二进制冲突说明限制并禁用不支持的文本处理。 |
| 工程隔离与补丁 | 新读取接口按 root/epoch 隔离；既有四个写命令携带 expectedRoot，拒绝 IPC 排队期间切工程的旧动作。解决冲突、提交等动作后刷新 SVN 与补丁扫描，避免使用旧清单。 |
| 状态与动效 | 沿用统一按钮、菜单、Modal、任务和动效 token；立即显示选中、pressed、focus、等待、错误与完成结果。扫描只显示真实条目数，不伪造百分比；支持减少动态效果。 |

SVN 仍采用文件级提交。完整三路编辑器、远端全历史搜索、按已提交 revision 生成发布补丁属于方案中明确列出的后续能力，本轮没有伪造这些功能。
