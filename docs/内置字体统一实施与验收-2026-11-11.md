# 内置字体统一实施与验收

日期：2026-11-11。

## 选择与原因

| 用途 | 内置字体 | 默认配置 |
| --- | --- | --- |
| Java、SQL、SQL 查看器 | JetBrains Mono | 13px、400 字重、关闭编程连字 |
| 界面、结果表格、代码中的中文回退 | Noto Sans SC | 正文 400、表头 600；结果数据保持 13px |

JetBrains Mono 的等宽字形便于扫描 SQL、编码和缩进，数字与相似字母容易区分。Noto Sans SC 覆盖简体中文，并提供相同来源的中英文字形与可变字重。两者均随应用提供，默认显示无需在用户电脑安装字体，也无需运行时访问字体 CDN。

原来的 SQL 编辑器优先使用本机 Cascadia Mono，结果表格使用 system-ui，查看器使用 Monaco 默认字体。因此电脑上安装的字体和系统版本不同，会得到不同字形。此次统一默认字体，同时保留用户自定义代码字体。

## 实施范围

- `desktop/src/assets/fonts/`：2 份 JetBrains Mono 可变 WOFF2（正常与斜体）、101 个 Noto Sans SC Unicode 分片。全部字体资源合计约 4.52 MiB，分片按页面实际字符加载。
- `desktop/src/fonts.css`：本地 font-face 与 `--font-sans` / `--font-mono`；由全局 CSS 接入。启动页预加载 Latin 与代码正常字体，文字加载期间保持可见。
- `desktop/src/lib/fonts.ts`：共用字体栈、字体加载通知与测量版本。监听只注册一次，不新增轮询。
- `editorPrefs.ts`、`useSqlDisplayPrefs.ts`：代码与 SQL 共用字体、字号、字重和连字配置；SQL 保留自己的换行、执行及编辑设置。修改显示偏好使用 `updateOptions`，不重建模型。
- SQL 查看器、设置预览、数据库页面的代码样式和查询反馈文字统一使用字体 token。
- 结果表格 CSS 与 canvas 测宽使用同序字体。字体加载后清除文本测宽缓存与结果集列宽缓存；重算自动列宽及换行行高，保留手调宽度、选区、滚动与编辑草稿。拖列宽期间冻结行高，松手再校准。

未修改版本号，未提交代码，未构建 exe 或安装包。

## 来源与许可证

- [JetBrains Mono 官方项目](https://github.com/JetBrains/JetBrainsMono)：官方可变 TTF 转换为 WOFF2，保留字形与字重。
- [Noto Sans SC 官方字体源](https://fonts.google.com/noto/specimen/Noto+Sans+SC)：Google Fonts 提供的 Unicode 分片。
- `desktop/public/licenses/fonts/` 随构建携带两份完整 OFL 1.1 许可证和字体清单。Noto 的许可证采用对应 Google Fonts 目录中的版本，包含 Adobe 版权声明。
- `manifest.json` 记录每份字体来源、字节数与 SHA256。`desktop/scripts/vendor-fonts.py` 用于开发时更新资源，需要 fonttools[woff]；应用运行时不依赖 Python 或网络下载。
