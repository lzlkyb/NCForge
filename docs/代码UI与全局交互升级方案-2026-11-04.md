# 代码 UI 与全局交互升级方案

日期：2026-11-04。范围：代码工作台，以及软件各模块用户主动触发的耗时操作。

方案已按 A–D 实施。本页保留实施前审查与设计依据，最终覆盖、测试和实机边界见《代码UI与全局交互升级实施验收-2026-11-04.md》。下文“当前覆盖”表为实施前基线，不代表升级后的状态。

## 结论与方向

当前没有做到全部耗时操作反馈完整覆盖。已有统一 Button 等待态、通知系统、页面/主题切换、降低动态效果支持；编译、搜索、数据库、服务和下载各有状态实现。但部分代码操作只有最终结果或错误提示，局部加载/错误/空状态混用，长任务状态分散。

保留柔光玻璃外壳和现有工作台。代码阅读区保持清晰实底。目标是让用户知道：点到什么、是否开始、正在处理什么、能否继续工作、结果在哪里、失败后怎么办。

## 当前覆盖与证据

“已有”表示源码可见相应状态链，不代表本轮已完成真实环境全流程验收。

| 场景 | 当前实现 | 需升级部分 |
| --- | --- | --- |

| 保存/重新加载 | useFileSave 有 saving 和同步重入锁；保存、编码及冲突有反馈 | 保存前格式化不在 saving 范围内；reloadFile 没有独立进行态；横幅动作需统一禁重入 |

| 文件结构 | OutlinePanel 复用符号缓存，语言服务不可用时说明原因 | 请求中/失败/确实无符号混用空状态；失败被转成没有可显示的符号 |
| 重构/语言动作 | 重构有失败原因、文档版本校验；调用层级已有 loading | runRefactor 可等待 60 秒但缺少可见进行态；格式化/组织导入等入口需逐项登记，复用 Monaco 自带反馈 |
| 编译/组合任务 | 编译有进行态、日志、结果、状态栏；ncTasks 有串行防重入 | 整条编译→投送→重启任务缺少响应式总状态；任务菜单只受 compiling 影响，非编译阶段可见状态不足 |
| 搜索/替换 | 搜索/替换按钮已有 loading，结果区有运行状态 | 补齐结果完成播报、慢查询、取消语义和切页后回到结果的一致性 |
| 数据库 | 连接、查询、写回、导出及只读切换有各自状态；表查询保留旧结果 | 单独审计元数据、NC 字典、按值反查、批量导入及独立会话；任务必须带连接/槽/来源，不把轮询标为用户任务 |
| SVN/补丁/服务/工程检查 | SVN 扫描与更新、补丁条目进度、服务启停 spinner、投送 busy、UPM running 已有 | 部分仅文字，跨页入口不统一；补齐真实阶段、耗时、后续动作和可取消性 |

## 优先修复的代码页 UX

1. 文件打开：点击立即选中目标，超过 300ms 时目标行或临时标签显示“正在读取 xxx”；保留当前已可读文件。同一文件请求合并，最后一次点击决定激活项；失败在目标处展示重试，不能无限等待。
2. jar 浏览：区分“读取库源码”“反编译类”“只读签名”阶段；允许继续浏览原文件，提供打开组件设置、重新读取等适用动作。取消能力需先核对后端；不把关闭提示当作取消进程。
3. 保存链：显示“格式化→写入→已保存→自动编译”状态。原有格式化失败仍继续保存的行为保留，结果说明格式化未完成。重复 Ctrl+S 必须从格式化阶段起防重入。
4. 工程切换：所有入口共用 switching 状态，说明目标工程和实际阶段；仍由原有未保存守卫决定是否继续。切换完成和语言服务准备完成是两个状态，不能过早显示全部就绪。
5. 文件结构：区分加载、成功为空、请求失败、语言服务未就绪；失败在面板内重试。结构按钮增加选中态、aria-expanded，关闭后焦点回到触发处。
6. 标签键盘：TabStrip 的父容器处理 Enter/Space，但未排除子关闭按钮的键盘事件，存在拦截原生关闭行为的风险。先写复现测试，再让关闭按钮保留原生行为，父标签只处理自身事件。
7. 操作层级：代码区域显示文件导航、阅读属性和少量常用动作；工程编译/任务保留在项目范围入口；较少使用的命令继续通过右键和命令面板。无需新增一排重复功能按钮。
8. 图标反馈：统一 hover、pressed、focus-visible、selected、disabled；不可用时就近说明原因。可点击行用底色/边线反馈，避免缩放整棵树或编辑器。
9. 窄窗口：工具条优先保留当前文件、导航、保存/运行及状态；次要动作收进“更多”。底部面板可折叠，当前标签可见，分屏允许合理最小宽度，保留现有拖动与键盘调节。

## 全软件等待与结果反馈标准

| 时长/场景 | 推荐反馈 | 约束 |
| --- | --- | --- |
| 小于 150ms | 按压/选中即时反馈，完成后状态更新 | 不强制 spinner，不延迟业务结果 |
| 150–300ms | 文案/局部 pending 状态 | 按实际入口决定是否立即显示，防止快速闪烁 |
| 超过 300ms | 按钮 spinner、区域轻提示或初次加载骨架 | 尺寸稳定；已读数据不被整块骨架抹掉 |
| 超过 2 秒 | 显示正在做的步骤和已用时间 | 用户可继续操作不相关区域；支持时显示取消 |
| 超过 10 秒 | 慢操作说明，保持阶段/日志入口 | 时间长不是失败，不假装超时；按操作真实超时处理 |
| 确定总量 | 真正的完成数/总数、字节数或百分比 | 百分比只依据后端已知总量 |
| 总量未知 | 活动指示＋当前阶段/计数 | 禁止把任意时间曲线显示为实际完成百分比 |
| 成功 | 结果摘要、耗时、打开结果/日志/文件入口 | 保存等高频操作优先状态栏，减少连续 toast |
| 失败/部分成功 | 就地原因、已完成范围、可用的重试/恢复动作 | 写操作不自动重放；有副作用时不能声称整体回滚 |
| 取消 | 取消中→后端确认停止→已取消 | 区分隐藏提示、放弃接收结果与终止实际操作 |

每个用户触发耗时入口必须具备：同步防重入、开始反馈、进行态、完成/失败/取消出口、晚到结果处理、切页处理、可访问播报。不能只加 finally 清 loading 就算完整。

## 统一实现方式

复用现有 Button、通知、状态栏、日志和后端进度事件，新增轻量的操作状态契约与可订阅的任务集合，不替换已有查询缓存或执行引擎。

- 记录任务 id、类型、说明、作用范围（工程/文件/连接/会话）、开始时间、阶段、状态和真实进度。
- 短操作保留局部 state；会跨页或较长的操作登记到共享集合，状态栏显示“2 项处理中”，点击查看详情与返回来源。
- 首版任务列表仅保存本次运行的必要摘要，业务查询内容、文件正文及凭据不进入默认历史。
- 相同入口用相同任务 key 防重入；是否允许同连接/同工程并发按原业务约束确定。只禁用冲突操作，不锁整个软件。
- UI 切页/卸载不代表结束。按任务性质继续后台运行、取消请求，或丢弃旧结果；旧工程/旧连接的结果不能改写新页面。
- IPC invoke 不是任务边界：内部轮询、心跳、自动补全、已有可读数据的静默刷新不弹全局等待提示。轮询健康问题用连接/服务状态表达。
- “可取消”由后端能力决定；不可取消的操作清楚说明。已有下载/升级流程直接适配现有状态，不能重复创建一套进度计算。

## 点击与切换动画规范

| 交互 | 建议时长 | 动作 |
| --- | --- | --- |
| 点击按压 | 80–100ms | 小按钮轻微下压或底色变化；数据行仅底色/边线 |
| hover / 焦点 | 100–140ms | 颜色、边框平滑变化，焦点环清晰可见 |
| 主页面切换 | 160–180ms | 沿用当前 ViewTransition，只作用于需要切换的内容 |
| 文件标签切换 | 100–140ms | 标签高亮/下划线反馈，已加载文件直接切模型；不为每次切文件遮盖全文 |
| 弹层/菜单 | 140–180ms | 小幅透明度与位移，关闭可中断，不阻挡点击 |
| 底部面板/折叠区 | 160–200ms | 面板内容轻淡入；拖动分隔条时跟手，不做延迟补间 |
| 等待态结束 | 120–160ms | 顺滑转为结果/完成态，不强行等待动画才显示结果 |

单一元素只由一套动效控制，避免 CSS、ViewTransition 和 FLIP 同时改 transform/opacity。编辑器、终端 canvas 与选区不整体缩放/移动，不重挂 Monaco。减少动态效果时取消位移/缩放与非必要切换动画，但保留文字状态、计数与静态等待标识。

## 实施顺序与验收

| 阶段 | 范围 | 验收 |
| --- | --- | --- |
| A：代码页反馈与正确性（优先） | 文件/库源码打开、保存链、工程切换、结构状态、标签键盘、按钮选中反馈 | 延迟注入后每个入口有可见状态；快速连点/快捷键不重复执行；无旧结果抢焦点、无未保存内容丢失 |
| B：全软件耗时入口清单与统一契约 | 登记各模块入口，接入可见任务列表、状态栏和结果动作 | 按清单逐项验证开始/进行/结束/失败/取消；切页仍可查任务并返回结果 |
| C：逐模块补齐 | 语言动作、SVN、补丁、NC 工程检查、投送/服务/调试、数据库、日志、设置、下载升级 | 所有已登记用户耗时入口符合标准；不新增静默后台任务的通知噪音；真实阶段和取消语义经后端确认 |
| D：切换动效与回归 | 按压、文件/面板切换、弹层、明暗/窄屏、减少动态效果 | 连续切换无白屏、跳字、焦点丢失；编辑器与终端不重建；等待态不造成布局跳动 |

完整入口清单字段：操作、触发位置、后端命令/事件、作用范围、开始反馈、等待反馈、完成反馈、失败恢复、取消能力、切页行为、测试证据。发布验收以这张清单为准，不以全文搜索 loading 的数量为准。

建议验证条件：

- 注入 100ms、800ms、5 秒、20 秒响应；超时、抛错、部分成功及取消。
- 快速点击两次、重复 Ctrl+S、键盘激活关闭按钮、中文输入法组合输入。
- 等待时切文件/工程/连接、关闭弹窗、切到其他页面再返回。
- 已有数据时刷新、缓存立即命中、空结果与请求失败。
- 1280px/1024px/560px，深浅主题、系统减少动态效果、旧 WebView 回退。
- 测试重要的行为和状态转换；截图在动效结束后采样。真实 NC 服务、SVN、Oracle 和安装取消用授权测试环境验收。

## 推荐取舍

优先交付 A＋B，再按 C 清单补齐，最后 D 收口。暂不扩成全新 IDE，不另建重复的结果页，不为短操作做全屏遮罩，不引入与业务无关的复杂动画。验收目标是反馈与交互正确性完整，动画服务于这些目标。
