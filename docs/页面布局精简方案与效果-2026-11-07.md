# 页面布局精简方案与效果

本轮已落实到前端源码，基于现有深青工作台风格继续精简布局。重点是减少独立工具行与常驻辅助区，让代码、日志、字段表、补丁目录及设置表单占据主要空间。

交互对照稿：[页面布局精简对照稿](../design/页面布局精简对照稿-2026-11-07.html)。可切换五个页面、调整前后、浅深主题，以及元数据专注模式。该文件是结构示意，不执行真实业务操作。

## 调整方案与对应效果

| 页面 | 调整前的占位问题 | 已实施调整 | 空间效果与适用条件 |
| --- | --- | --- | --- |
| 服务控制台 | 两个服务来源占一整列；详情、投送和设置存在重复入口 | 中间件、客户端及各自状态并入运行工具栏；低频操作集中在“更多服务工具” | 原固定侧栏在通常宽度为 186px，较窄容器为 170px / 136px，移除后这些宽度归还日志。窄窗分行显示来源和操作，保证按钮可用 |
| 元数据 | 实体选择与字段操作分成两行；宽屏资源和属性栏长期停靠 | 实体选择、实体菜单、字段搜索、新增与批量操作共用一行；新增专注模式 | 常规视图少一行头部，预计约 40px。双侧栏按默认宽度停靠时，专注可释放约 514px 横向空间（224 + 5 + 280 + 5）；原本已用抽屉的窄窗不会重复计算这部分收益 |
| 补丁打包 | 选中文件的完整详情常驻在目录树下方，最高占 232px | 默认显示摘要，点击展开完整详情；异常或手动改判的文件默认展开 | 正常状态收为约 37px 摘要，理论最多释放约 195px 高度；长文件名或窄窗换行时以实际摘要高度为准 |
| 数据库 | “查找数据库对象”单独占一行 | 查找图标并入连接标题栏，保留名称提示与快捷键 | 连接与对象树增加一整行可视高度；SQL 编辑器和结果表继续使用现有紧凑布局 |
| 设置 | 正文最大宽度固定 800px，外边距与设置行留白较大 | 最大宽度调至 1120px；正文边距由 28×32px 调至 20×24px；每行上下留白各减少 4px | 宽屏表单宽度上限增加 40%；每条设置项减少 8px 纵向留白。“关于”仍保留 800px 上限，说明文字控制在 70ch 内 |

以上数值来自源码布局规则和默认尺寸推算，**不是浏览器实测结果**。实际收益受到窗口、主题密度、侧栏自定义宽度、文案换行及展开状态影响。

代码编辑、SVN 审查及日志排查沿用工作区已有的专注布局、工具栏合并和低频操作收纳。本轮没有将这些既有成果重复计为新增收益。

## 功能完整性

- 服务：两个来源的状态、启动、停止、取消、重启、调试和故障反馈保留。来源切换使用同一组件树，避免切换时丢失键盘焦点；运行详情、启动设置、命令行、日志位置、元数据投送与报文解密各保留一个菜单入口。
- 元数据：专注只改变停靠方式，不卸载文档或表格。测试覆盖草稿、选中字段、滚动容器和滚动位置保持；资源、属性检查器仍可按需打开。实体菜单保留新增实体和实体属性，字段批量操作不变。
- 补丁：摘要保留文件名、模块、落位层、编译配对、异常和手动改判标记；展开后仍有完整产物、目标目录、判层依据及自动 / 标准层 / hyext 改判。用户手动收起异常详情后，异常摘要仍可见。
- 数据库：复用原对象查找逻辑和对话框，Ctrl+Alt+O 保留。没有更改 SQL 执行、事务、连接或结果处理。
- 设置：仅调整宽度与留白；控件大小、搜索定位、折叠组自动展开和滚动记忆保持。

收纳的取舍是低频操作增加一次菜单或展开动作。高频操作、当前对象与异常状态继续常驻。未通过缩小代码字号、表格行高或点击目标换取空间。

## 验证记录

- TypeScript 项目检查通过。
- 直接相关的 11 个测试文件、55 项单元测试通过，涵盖元数据草稿与实体切换、服务状态与键盘导航、补丁异常与改判、对象查找和设置导航。
- 组件体量、设计 token、UI 约定及 knip 孤立文件 / 依赖门禁通过；修改文件的 ESLint 检查通过。
- Impeccable 布局静态扫描返回空发现列表，原始结果见 [布局静态检查](页面布局精简验收-2026-11-07/布局静态检查.json)。静态扫描不能替代实际布局检查。
- 对照稿的五页面切换、前后切换、专注切换和主题切换通过 DOM 交互检查。未将 DOM 检查计为视觉验收。
- 差异检查通过。

常规 Vitest 加载器在收集测试前因 Windows 子进程 `spawn EPERM` 中断。随后在受限环境使用临时配置：线程池、TypeScript 进程内转换、关闭 esbuild 转换、保留符号链接路径。执行的是上述同一组测试，未跳过用例；项目正式 Vite 配置保持不变。

## 尚未完成的验证

浏览器验收脚本已准备在 `desktop/scripts/layout-space-acceptance.mjs`，使用生产前端和内存 IPC，覆盖六种窗口 / 主题组合、五个页面及新增入口。`--baseline` 保存调整前结果，默认保存调整后结果。当前生产目录尚未重建，因此没有生成本轮浏览器测量结果。

本地无头浏览器启动在沙箱中被拒绝。经用户明确允许重试后，自动审批服务仍返回 `content-blocked / review failure`；受控浏览器访问本地预览也未能通过相同的审批服务。该结果是审核服务失败，并非判定验收操作不安全。浏览器截图、实际尺寸、溢出检查及生产构建验证仍待运行，不能视为已通过。
