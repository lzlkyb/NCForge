# 标签挤压与窄栏布局排查记录

用户截图中的补丁清单“标准”“未编译”逐字换行并跨越列表行。本轮保留既有深青灰主题与操作流程，修复这处问题并检查项目中同类布局。

## 已修复

| 位置 | 原因或同类风险 | 修复 |
| --- | --- | --- |
| 共享侧栏中的补丁状态 | 状态区被限制为 80px，内部两个标签挤压换行 | 去掉状态区的固定宽度限制；状态不收缩，文件名按需省略 |
| 最小 180px 补丁侧栏 | 保留状态后，文件名可用宽度过小 | 220px 及以下按容器宽度将状态放在文件名下方，行高自动调整 |
| 补丁与版本控制分组 | 固定 28px 行高叠加停靠层上下内边距；长模块名与数量、操作争宽度 | 改为最小行高；模块名独立省略，完整名称保留在提示中；数量不收缩 |
| 补丁筛选、批量操作、视图与树头 | 标签文字和计数可能在窄空间内拆开；树头多个操作争宽度 | 短标签保持横向、不收缩；树头按完整项目换行 |
| 补丁清单底部 | 阻断数量与进度争宽度；最窄状态下警告图标单独掉到一行 | 数量作为整体换行；警告图标固定，旁边说明可以正常换行 |
| 版本控制筛选 | 中文标签与计数可能被压缩 | 整个筛选按钮保持横向、不收缩 |
| NC 服务状态 | 服务名称与状态标签共享一行 | 名称可省略，状态完整保留；状态组不超过容器宽度 |
| 日志排查 | 操作按钮、来源标签、元信息名称可能拆字 | 短标签不收缩、不拆字；长值允许省略 |
| 数据库 | 环境徽章、文本操作与表页标签的横排约束不完整 | 保持横向；已有工具栏换行及标签滚动行为保留 |
| 公共 Button | 文本可能随父级空间压缩，在固定按钮高度内拆字 | 统一保持横向并禁止按钮自身收缩；保留现有忙碌状态 |

源码排查覆盖 `desktop/src/` 下的 19 份模块样式，以及相关真实组件、共享停靠层和公共控件。对已具备正常省略、整项换行或滚动能力的结构未重复改动。此次范围是标签挤压、文字逐字换行与固定行高造成的同类问题，不代表全部软件功能已完成验收。

## 验证

- 复用正在运行的 NCForge 开发窗口；实际补丁扫描显示 96 项、已勾 42 项。
- 259px 侧栏：标准、未编译、整文件和 class 数量横排；行间不重叠。
- 拖到最小 180px：状态位于文件名下一行；两者可读；警告图标与说明同行起始。
- 最小侧栏的深浅主题均已目视确认。检查后恢复浅色与 259px 侧栏。
- ESLint、组件体量、设计 token、UI 约定、布局检测、TypeScript 转译语法、19 份 CSS 语法、修复稿与正式样式同步、`git diff --check` 均通过。
- 增加补丁清单的完整名称、状态保留、查看与勾选互不触发回归用例；增加公共按钮忙碌期间防重复操作的回归用例。
- 新增 Vitest 用例尚未执行：可用内存约 3.5GiB，低于项目 `CLAUDE.md` §8.3.2 的 4GiB 重任务门槛。未启动额外测试浏览器、编译或打包进程。
- 其他模块的修复完成源码与样式检查，尚未逐个完成原生窗口视觉验收。
