# 工作台材质升级实施与验收

已将验收后的设计稿接入正式前端。经典和柔光玻璃共用基础样式：窗口及面板圆角、胶囊标签、连续背景、单层搜索、轻微层次和少线布局；切换材质不会恢复旧的直角和硬接缝。

## 实施范围

- 正式入口在所有基础样式后加载 `desktop/src/workbench-material.css`，设计稿不再重复实现工作台材质。
- 窗口 16px、整体工作台外壳 14px；资源栏、文档、底部面板和状态栏共用外壳裁切与一层轻影，顶部标题栏和左侧导航位于外壳之外。内部资源栏、编辑器和结果区不带独立圆角或阴影；窄窗口覆盖抽屉保留 12px 圆角。
- 代码、版本控制、数据库、元数据、日志和设置均走同一个公共外壳；资源栏用轻微底色区分，版本页、日志页、代码工具栏和调试检查器同步减少结构分割线。
- 菜单、命令面板、补全、悬停及修复菜单共享圆角和层次；经典使用实底，柔光玻璃使用半透明模糊。
- 元数据资源栏去常驻分隔线，搜索框只保留一层背景，空状态集中图标、说明和原有操作，窄窗口资源抽屉同步圆角与阴影。
- 保留现有字号、标准/舒适密度、表格选中与错误反馈。分隔条静止隐藏，悬停和键盘聚焦时出现，拖动和键盘调整继续有效。
- 低窗口的筛选区更早进入内部滚动，为外围圆角留白保留空间，150% 缩放时结果区仍可容纳两行舒适密度数据，查询按钮保持可见。
- 代码、数据库表格、日志与长连接表单保持实底阅读面。

材质路径：「设置 → 外观与启动 → 界面材质」。明暗、密度、材质独立保存；新用户默认经典，现有用户的已存偏好继续生效。

## 验证

- 7 个相关 Vitest 文件共 101 项通过，覆盖外观设置、工作台、元数据与查询辅助。
- `npm run vite:build` 通过，包含 TypeScript 检查与正式前端构建。
- `node scripts/material-workbench-acceptance.mjs`：133 项通过；读取编译后的正式产物，覆盖浅色/深色 × 经典/柔光玻璃，页面错误与 CSP 违规均为 0。数据与服务状态均使用内存模拟，不连接真实数据库或启动 NC 服务。
- 正式产物检查包含六个页面的完整外壳范围、四角裁切、共享阴影、状态栏归属、内部无独立圆角、连续工作面、标准密度、选中范围、材质保存、菜单材质、设置行、元数据搜索及焦点、空状态、560px 资源抽屉和横向溢出。浅色经典、深色玻璃另覆盖六页的 1024px 与 560px 窗口。
- 代码底部面板及 NC 服务面板纳入同一外壳，键盘调整底部面板和数据库结果区高度保持有效；服务控制台按真实接口形状模拟读取，正常空状态无读取错误。日志列表竖线、设置分隔条白缝、服务工具栏和页脚横线均已消除。
- `node --test scripts/db-visual-production.test.mjs` 通过：覆盖 SQL/表页的四种主题材质组合及四种窗口尺寸，核对虚拟列表、密度切换、文本对比度、执行历史与片段、等待/停止/错误/空结果、事务回滚、宽列滚动、低窗口筛选、连接弹窗焦点和数据字典。旧测试的 IPC 模拟及控件名称已对齐当前组件。
- 已批量检查六页正式产物截图；修复后集中确认浅色经典日志、设置、服务控制台、深色玻璃元数据及 560px 代码页的整体外壳。
- 原设计稿 `verify.mjs` 的 41 项视觉与交互检查通过，包含手工填写 SQL、通用查询辅助和 LEFT JOIN 快速修复；页面脚本错误为 0。
- 设计 token、界面约定、组件体量和构建体积检查通过；材质样式的静态设计检测无发现。
