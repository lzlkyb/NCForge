# NCForge 交互设计稿

## Platform
web

## Users
长时间使用 Windows 的 NC 开发人员。用户已确认文件编辑、工程搜索、NC 日志和数据库为高频操作。

## Product Purpose
在同一个工作上下文中编辑源码、查数据、排查日志、编译模块并处理版本控制与补丁。

## Capabilities and Constraints
本次只交付独立 HTML 交互设计稿，不修改 Tauri / React 应用源码，不接入真实数据库、SVN、文件写入或服务控制。示例操作明确标识，编辑内容保留于设计稿会话。

## Approved Direction
用户确认采用深青与中性灰，并要求按桌面软件实际像素尺寸制作可交互设计稿。沿用现有图标、软件名称、工作台结构和已有快捷键映射。
