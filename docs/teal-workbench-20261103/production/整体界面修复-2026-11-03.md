## 已处理的问题

| 审查问题 | 正式源码处理 |
| --- | --- |
| 日志详情与追踪请求不一致 | 保存完整选中记录；追踪绑定 callid，切请求清理，旧异步响应作废；时间线中的记录可独立打开详情 |
| 数据库待提交提醒遗漏独立会话 | 汇总当前连接主会话与各 SQL 槽，同槽去重；菜单逐个定位，缺少主会话文档时展示只读概况 |
| 自动提交事后提示 | 有未提交写入时先确认；等待确认或申请槽后重新核对标签、连接、槽、活动标签和执行状态；切换单飞并锁定连接和执行按钮 |
| 关闭标签或换库期间槽申请返回 | 释放已不属于原标签的槽；返回事务仅写回仍持有原槽的标签；槽状态未知时不使用主会话事务 |
| 搜索长行看不到命中 | 围绕首个有效命中生成短上下文，保护 emoji 边界；只处理显示副本，原行号和 UTF-16 定位不变；缩小行号与缩进占用 |
| 中文输入与键盘规则不一致 | 搜索、日志和公共菜单避开输入法组词；连接选择支持方向键、Home/End、Enter/Space、Escape；数据库标签支持横向导航和关闭后的焦点恢复 |
| 可访问名称与状态缺口 | 连接表单八字段关联标签；连接选择、标签面板、树展开、菜单多选、设置字体和命令行弹窗补齐相应名称与状态 |
| 菜单关闭与长列表焦点 | Escape、操作完成归还焦点，外部点击让目标接管；长菜单键盘导航滚入可见区域；日志长列表使用单个 Tab 入口 |
| 日志重复导航修改隐藏侧栏偏好 | 进入日志、返回代码、重复点击日志均保留代码侧栏偏好；其他工具按原有规则展开侧栏 |
| 日志来源多、旧提示不准确 | 四个常用来源及所有已选来源保持可见，其余可搜索多选；保留来源搜索草稿；统一“仅问题与慢 SQL”文案，说明全文检索的条件 |
| 小点击区域、文字密度、窄窗口 | 标签关闭 26px、设置搜索清除 24px；新增可保存的标准 / 舒适密度；按实际内容宽度适配工具条，日志来源换行与有界滚动 |

舒适模式调整界面字体和控件，不改变虚拟文件树、虚拟网格的行高或编辑器设置，避免滚动定位失准。首帧恢复已保存密度，数据库懒加载样式保持相同选择。
