## 已实施

- 浅色主色 `#24766e`、深色主色 `#78bfb4`；窗口框架使用中性灰，内容区保持连续表面。
- 标题栏 40px，紧凑导航 60px、展开 148px，标签 36px，状态栏 26px；内容外框顶部圆角 8px。
- 普通控件圆角 6px、菜单 10px、弹窗 12px；组合输入框统一由外层承载 2px 焦点，内部输入不叠加光晕。
- 标题栏新增真实应用菜单、最近工作区和布局菜单。工作区选择复用原有保存与切换流程，文件页尚未加载时保留请求，重复效果执行不重复切换；从工具页选择代码分屏或代码面板时回到代码页，让操作结果可见。
- 日志使用共享文档停靠区，进入日志时收起资源侧栏，返回代码恢复原侧栏偏好；文件模型和日志输入继续保留。版本控制导航直接显示工具文档。
- 数据库、字典、服务、调试、版本控制、补丁与工程关联使用统一密度和连续分区。高级入口分层收进菜单，原有业务调用、事务与确认流程保持。
- 修复搜索侧栏下工作区输入不可见、状态栏被懒加载样式覆盖和主题事件早于实际配色切换的问题。
- 页面切换只捕获有实际尺寸的内容框；透明停靠包装层不再承担动画，旧 WebView 使用不移动内容的淡入回退。
- 新用户默认实色材质，已有玻璃偏好继续保留；玻璃选项也沿用相同色系。开窗骨架同步新框架并保留减少动态效果支持。

## 内存满足后执行

同一时间只运行一个重任务，Vitest 最多 2 个工作线程，本轮建议 1 个。

1. `tsc --noEmit` 与 ESLint。
2. 上述回归文件，再检查现有 FilesTab、TreeViewOptions、ResultTable、ResultPanel、DictWorkspace、ImportDialog、InsertExportDialog、SessionDrawer。
3. `npm run vite:build`，只构建前端。
4. 在 1280/1100/850px 与深浅主题下检查菜单定位、工具条换行、单一焦点、SQL/文件状态；原生窗口检查拖动、最大化和退出前保存守卫。
