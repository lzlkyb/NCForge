# 代码工作台布局与图标优化实施与验收

本轮按已确认的工作台方向实施代码页优化，重点覆盖用户截图中的资源树工具条、文件标签与路径导航、分屏操作和空编辑器。核心操作顺序为：找文件 → 切换文档 → 定位代码 → 编译或运行任务。

结构参考：[代码工作台布局与图标优化设计稿](../design/代码工作台布局与图标优化-2026-11-07.html)。该 HTML 是设计参考，展示代码与空编辑器两种状态，可调整侧栏宽度；示例文件与代码不代表实际运行数据。

## 调整与效果

下表尺寸为源码中的 CSS px 规格，效果说明基于布局结构与交互测试；未给出实机面积测量或缩放测量。

| 区域 | 调整前 | 已实施的调整 | 改进效果 |
| --- | --- | --- | --- |
| 资源树头部 | 标题与工具分两行；五个常驻工具图标 | 36 px 单行，保留文件/包切换；常驻工具为自动定位、名称过滤、全工程搜索、更多四个 | 减少一排工具占用；自动定位按用户使用频率保留一键操作 |
| 资源树设置 | 自动定位、视图设置分别常驻；名称过滤与设置重复使用滑杆 | 自动定位使用顶部靶心开关并显示状态；压缩中间包、NC 结构、跨工程直接切换收入更多菜单 | 高频操作可直接切换，低频设置仍可访问且独立保存，菜单没有重复定位入口 |
| 文件标签与导航 | 共享路径导航在标签上方 | 文件标签 → 本组路径与阅读工具 → 编辑器正文；导航行由 36 px 收为 32 px | 层级更接近文档工作流，正文按规格获得 4 px 高度 |
| 标签滚动 | 整条标签区横向滚动，执行工具也可能被带出视野 | 仅文件标签区域滚动；所有标签入口与执行工具独立保留 | 打开较多文件时，编译、任务及分组操作更容易找到 |
| 分屏 | 执行工具只在左组，窄窗口聚焦右组时会被隐藏 | 保留一套工具，窄分屏跟随可见组；极窄区通过分组菜单切换左右组 | 修复执行入口不可达；切换焦点保留两组文件与模型 |
| 分屏路径与历史 | 共享导航不直接表达每个组的文件来源 | 活动组显示完整阅读工具；另一组显示自己的路径，不使用活动组光标生成符号链；历史面板单实例 | 避免路径和符号串组，历史来源与未保存限制随活动文件更新 |
| 空编辑器 | 最大宽度 420 px；最近文件与快捷键纵向堆叠，文件名和目录同排挤压 | 最大宽度 780 px，最近文件与快捷键使用平面两区；文件名与目录分行；窄区单列，短窗口可滚动 | 宽屏利用更充分，长目录更容易分辨，打开文件的主入口更突出 |
| 工具图标 | 常规图形多为 12–14 px；编译与任务均为播放图标，分组与布局同形 | 常规工具图形统一 16 px，图标点击区 28 px；文件/包分段按钮至少 24 px 高 | 提高识别性与点击容错，图形和功能对应关系更清晰 |

“五个工具收为四个”只计资源树的常驻工具按钮，文件/包视图切换仍保留直接入口。自动定位根据用户后续反馈恢复常驻；最窄侧栏只收紧分段按钮和间距，工具图标仍为 16 px、点击区仍为 28 px。

## 图标语义

| 功能 | 图形 | 用途 |
| --- | --- | --- |
| 自动定位 | 靶心 | 一键切换打开文件时在资源树中展开并定位，开启时高亮，偏好独立保存 |
| 名称过滤 | 漏斗 | 过滤已加载文件名与包名 |
| 全工程搜索 | 放大镜 | 进入工程内容搜索 |
| 编译 | 锤子 | 编译活动编辑器组文件所属模块 |
| NC 任务 | 终端 | 运行编译、投送、重启及补丁任务组合 |
| 编辑器分组 | 双列面板 | 打开、聚焦、交换、等宽与合并编辑器组 |
| 展开阅读 / 恢复布局 | 展开 / 收合四角 | 表达面板阅读状态，区分系统窗口方框 |

图形沿用现有内联 SVG 系统与主题 token。导航主入口、文件类型、状态标记与辅助箭头按各自层级保留尺寸，不统一放大为同一规格。

## 功能保留与交互边界

资源树更多菜单完整保留新建文件、新建文件夹、更换工作区、最近工程与三项低频视图偏好。自动定位常驻顶部，手动“在文件树中显示”仍不受它影响。目录选择仍保留取消、错误提示、等待反馈及重复点击保护；NC 结构不可用时仍说明原因；多工程编译与 SVN 的作用范围仍显示。

阅读区保留后退、前进、跳转记录、小地图、文件结构、固定结构与本地历史。分屏各组仍保留自己的活动文件、比例、预览和未保存状态；非活动组的路径不会使用另一组光标生成符号位置。历史与结构浮层从标签及导航下方展开，受可用正文高度约束。

空编辑器继续显示当前工程、真实路径、当前工程最近五个文件以及完整快捷键，文件点击使用完整路径，“转到文件”仍调用现有入口。
