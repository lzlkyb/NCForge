# 数据库双主题 UI 实施与验收

用户确认方案后，已将升级落实到真实 React 页面。浅色、深色以及玻璃、实色材质均覆盖；数据库连接、查询、提交、回滚、停止和生产写确认继续使用现有业务接口。

## 已完成

- 连接树改为名称与账号两行，环境以文字标识，文档选中统一深青。连接选择只在 SQL 上下文中出现一次，保留事务切换时的连接与执行锁。
- 执行范围放在工具条，历史、片段和工具按空间使用图文或图标入口；完整快捷键在执行菜单和提示中保留。
- 结果对照、比较和关联收进结果工具；列布局、筛选、复制、导出与单元格详情仍可直接访问。查询来源与读取范围并入结果底栏，完整 SQL 可展开读取。
- 表格正文、中文名、辅助信息与控件统一排版。默认行高为紧凑 26px、舒适 30px，表头为 40px、44px；CSS、虚拟位置和键盘滚动共用几何。
- 筛选摘要与固定查询入口、结构、索引、DDL、历史、片段、会话、连接配置、导入导出、列布局、对比、关联、修改复核和数据字典统一样式。
- 连接表单分为基本信息、连接与认证、运行方式。头尾固定，低窗口正文内部滚动；数据库弹窗在玻璃材质下也使用不透明阅读底色。
- 按下、悬停、选中与等待反馈统一，支持减弱动效。空结果提供调整查询提示，本地筛选无匹配时可直接清除筛选。

已有保存的列宽继续按用户设置使用。需要采用新的默认估算时，在「列布局」中选择「自动适应列宽」。

## 验收过程中修复的问题

1. 旧容器样式在文档宽度小于 720px 时强制 SQL 辅助操作另起一行，挤压结果区。移除强制换行，窄区域保留有名称和提示的图标入口。
2. 在结果末尾切换密度时，浏览器先按新的内容高度夹紧滚动位置，代码再缩放一次。改用上一帧的滚动状态，保留正确位置并按真实边界夹紧。
3. 原始列宽只按字符数估算，中文名称和部分短值被截断。按中文显示宽度估算并补齐内边距，仍限制样本数和最大列宽。
4. 提交和回滚同一帧连续点击缺少同步锁。增加请求锁，等待期间保留按钮反馈，完成后恢复。
5. 玻璃弹窗透出背景中的 SQL 和数据。数据库表单及长文弹窗改用稳定实底，保留外壳材质。
