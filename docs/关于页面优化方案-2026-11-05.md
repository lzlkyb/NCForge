# 关于页面优化方案

## 已确认的问题

- 项目仓库仍为 `your-name/your-app`，按钮被禁用；元信息中的作者也仍为占位值。真实 Git remote 是 `https://github.com/lzlkyb/NCForge.git`，项目许可证为 MIT，版权主体为 `nc-forge contributors`。
- 原始平台名 `windows` 直接显示，没有面向用户的名称；信息成功返回但缺少版本时，页面仍显示“读取中”，无法恢复。
- 产品名、版本、平台与操作分散在拉长的设置行中，首屏缺少清晰的信息主次。
- 更新历史当前有 348 条记录，约 3 万字，全部直接渲染；没有版本切换、分类、搜索、摘要、显式关闭按钮。
- 更新日志生成器不识别“更新摘要”，并将技术内容归入普通改进；原始 Markdown 标记和开发记录混入用户阅读区。
- 许可只有名称，没有正文入口；排查问题缺少版本信息复制入口。

证据：`docs/about-ui-20261105/before-about.png`、`before-history.png`、`before.json`，以及关于组件、更新记录生成器与实际元信息源码。

## 选定方向

沿用柔光玻璃与实色材质、浅深主题、工作台侧栏和现有字号/控件规范。正文保持清晰阅读底色，改为三段信息；更新历史用独立阅读弹窗，固定标题、筛选和关闭入口，长内容在内部滚动。

1. **产品与运行信息**：应用图标、名称、真实运行版本及平台集中展示。提供检查更新、查看历史、复制版本信息；复用现有更新服务和安装确认流程。正在读取、失败、缺少字段分别处理，错误允许重试，版本未知时不冒充最新版本。
2. **本版本更新**：按运行版本找到对应记录，先展示更新摘要与少量要点，再展开完整记录。没有对应记录时明确标注“随包更新记录”；记录日期不当作构建时间。读取及生成统一使用 CHANGELOG.md，保留全部历史内容。
3. **项目与许可**：配置真实仓库链接、问题反馈入口、MIT 正文。版权取许可证，移除作者占位，未提供的个人姓名不编造。技术信息按需展开，复制内容只包含产品、版本、平台和公开仓库，不含工作区路径或数据库连接。

更新历史增加版本选择、类别筛选、关键词搜索、空结果与清除筛选，摘要先于条目，技术记录按需展开。处理内联代码的阅读样式，长路径与长文本可换行。关闭、Esc、焦点归还统一使用现有 Modal 行为。

## 实施范围

- 关于组件及其专用样式；拆出更新历史与许可阅读组件，避免继续增大 SettingsTab。
- 元信息配置、更新历史生成器及必要的数据类型。生成文件由脚本生成，不手改；不调整版本号。
- 保留设置搜索定位、标题栏和欢迎条的历史入口。所有异步按钮显示等待与失败反馈，同一操作进行中防止重复触发。
- 不改其他设置分类及此前 SQL 修复；不提交，不构建 exe/安装包。

## 实施验收

- 设置、更新上下文、更新说明、徽章及升级欢迎条相关 15 个测试文件、129 项测试通过；日志解析与 ZIP 相关 8 项脚本测试通过。脚本测试接入 `npm test` 的前置步骤，避免 CI 漏掉日志解析回归。
- TypeScript、定向 ESLint、组件体量、设计 token、UI 约定及孤立文件门禁通过。已用自定义 `code-review` 执行本批 diff 检查，并通读新增源码，保留其他任务的改动。
- 生产前端构建通过；JS 体积为 4836KB raw / 1373KB gzip，较原预算增加 13KB / 4KB。增加来自关于页交互、许可正文与保留技术记录，无新增依赖；预算按真实产物调整，最大 chunk 预算保持 3171KB。
- 生产浏览器使用真实 dist、Tauri 配置 CSP、构建期样式 nonce 和脚本 hash，系统与业务 IPC 使用本地模拟，不连接数据库。版本/许可真实性、复制、链接失败恢复、历史选择/搜索/类别/展开、两次 Esc、焦点返回与 Tab 环绕、版本异常重试及更新检查等待均通过。
- 1280×840、1024×600、560×700 浅深玻璃、560×700 实色及 819×672（125% 等效）的 6 组布局均无页面或正文横向溢出；历史正文保留至少 100px 可读高度，关闭入口始终可见。截图与测量记录见 `docs/about-ui-20261105/production.json`。
- 许可从根目录 LICENSE 通过 Vite 虚拟模块打包，文件边界不扩大。历史搜索使用捕获阶段处理 Esc，输入法组词时不抢按键；下载到 100% 后明确显示校验阶段。

验收范围是生产前端与安装版 CSP 的浏览器模拟，未更新或声称验收已有安装包。构建期间采样可用内存约 3.0–3.5GiB，未持续采样最低值，该结果不作为冷构建或 Rust 的内存上限。
