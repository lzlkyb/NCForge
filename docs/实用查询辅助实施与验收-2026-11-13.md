# 实用查询辅助实施与验收

日期：2026-11-13。实施用户确认的三项辅助：按明细条件查完整结果、粘贴一列值转 IN、档案引用键展开编码与名称。沿用 SQL 编辑器与补全列表，值直接写在 SQL 内。

## 1. 按关联条件查完整结果

在新语句位置输入表名或 NC 中文名，选择“主表名 · 按关联条件查完整结果 关联表名”。光标直接落在内层 `x.` 后，自动打开字段候选；选择字段及条件后填写值。

例如按物料筛采购订单，仍返回匹配订单的全部明细：

```sql
SELECT a.*, b.*
FROM po_order a
LEFT JOIN po_order_b b
    ON b.pk_order = a.pk_order
WHERE EXISTS (
    SELECT 1
    FROM po_order_b x
    WHERE x.pk_order = a.pk_order
      AND (x.pk_material = '')
);
```

括号内可继续增加 `AND` / `OR` 条件，关联键仍在括号外约束当前单据。筛选只放在 `x` 中，外层 `b` 保留全部关联行。表名与配对字段来自当前 schema 的外键或 NC 类引用；复合关联键全部参与，不要求有单号字段。

模板名称使用“关联条件查完整结果”，因为元数据能够确认关联关系，但不一定能确认每个关联表的业务身份都是单据明细。

## 2. 粘贴一列值转为 IN

先写明字段，再粘贴并选中整列，右键选择“转为 IN 条件”：

```sql
SELECT * FROM po_order_b b
WHERE b.pk_material
001
002
001
O'Brien
;
```

选中 `001` 至 `O'Brien` 的四行后，生成：

```sql
SELECT * FROM po_order_b b
WHERE b.pk_material IN ('001', '002', 'O''Brien');
```

也可以先写 `b.pk_material IN (...)`，选中括号内完整的一列值再转换。操作使用编辑器选区，不读取剪贴板。

- 按实际字段类型决定是否加引号，文本保留前导零并转义单引号；数值严格校验，保持原有精度。
- 按出现顺序去重，空行跳过；已有每行单引号 SQL 字符串可保留其值。多列粘贴、未知类型、日期等暂不支持的类型给出提示。
- Oracle 每组最多 1000 项，多组生成 `(字段 IN (...) OR 字段 IN (...))`，保留外围 `AND` / `NOT` 作用范围。
- 只允许完整的新条件或完整 IN 列表；字段尾部、函数/算术/已有比较、局部列表、未来 JOIN 别名、来源歧义及 `NOT IN` 不转换。
- 可通过 `Ctrl+Z` 一次撤销。读取字段期间连接、schema、表结构、模型、光标或选区变化，会丢弃迟到结果。

## 3. 档案主键展开编码和名称

在普通最外层 `SELECT` 中输入引用字段，如 `b.pk_material`，按 `Ctrl+空格` 选择“b.pk_material · 展开档案编码和名称”。一次加入引用主键、档案编码、档案名称及 `LEFT JOIN`。

实际编码/名称字段以当前档案元数据为准。示意：

```sql
SELECT b.pk_material,
    ref1.code AS pk_material_code,
    ref1.name AS pk_material_name
FROM po_order_b b
LEFT JOIN bd_material ref1
    ON b.pk_material = ref1.pk_material
WHERE b.pk_order = '';
```

- 只使用当前 schema 已声明的出向外键/NC 引用，且目标关联列覆盖完整真实主键，保证新关联每行最多匹配一行。
- 根据字段中文说明/注释中的“编码”“名称”识别实际字段；没有描述时，仅接受唯一的常规 `code/vcode` 与 `name/vname` 字段。任何角色不明确时隐藏候选。
- 必须确认关联两侧所有真实字段；本期仅支持 Oracle 普通全大写物理对象，实际小写或混合大小写的引用对象不折叠猜测。
- 避开已有表别名和已知输出名；可复用同条件的已有 `LEFT JOIN`，有额外 ON 筛选的关联不复用。
- SELECT 字段与 JOIN 一次加入，可一次撤销；已有 WHERE、前后语句保持原样。
- DISTINCT、聚合/分组、表达式、集合查询、逗号/NATURAL/USING 关联、嵌套 SELECT 和 INSERT SELECT 不提供展开，避免改变结果含义或固定列数。

## 范围

关联模板与档案展开沿用已连接 Oracle 当前 schema 的元数据路径；批量转换按编辑器当前 SQL 方言和真实字段类型工作。查询/档案候选由现有“查询与条件模板”设置控制；批量转换是独立右键操作。所有辅助只编辑 SQL，执行仍由用户主动触发；没有增加填写参数面板。
