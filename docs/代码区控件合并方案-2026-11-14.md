# 代码区控件合并方案

日期：2026-11-14。状态：建议方案，尚未实施本轮改动。

## 目标与判断

延续「工程搜索进入顶部浮层」的方向，让用途相同的操作共用界面，减少常驻按钮和工具行。高频动作保留直接入口，低频配置进入对应功能菜单。

当前标签条已经承载分组与开发任务；窄窗口已经收纳阅读工具；底部改动面板已经包含时间线、多文件比较与审查清单；编码、行尾等文件信息也已有聚合菜单。后续应围绕这些已有界面继续合并。

## 推荐合并项

| 优先级 | 当前分散功能 | 合并后 | 具体交互与收益 |
| --- | --- | --- | --- |
| 第一批 | 上下文行的编译、标签条的开发任务 | 标签条一个「编译当前模块 ▾」入口 | 主按钮始终编译当前模块；下拉提供编译全部、更新到 NC、编译并重启、打包补丁及自定义任务。编译目标随当前活动编辑器组确定。减少重复按钮，保留一键编译。 |
| 第二批，重点推荐 | 文件结构浮层、顶部符号快跳 | 顶部「符号」模式承担结构快跳 | 打开后显示当前文件的类、方法、字段，输入过滤、回车定位。需要长期查看时可固定为结构侧栏。撤掉常驻「结构」按钮，但保留快捷键和命令入口。 |
| 第二批，重点推荐 | 本地历史浮层、改动面板、路径行的基线及核对操作 | 共用「改动」面板 | 本地历史入口打开改动面板并自动定位当前文件的归档版本；版本比较、恢复与审查在同一面板内完成。路径行只留可点击的改动摘要，基线选择与核对工具放进面板；保留上一/下一未审改动快捷键。 |
| 第一批 | 分组、小地图开关、结构停靠、面板显示配置 | 标签条「布局 ▾」菜单 | 当前组分屏、交换、恢复等宽、合并，以及小地图和侧栏显示在一个布局菜单里。结构内容查询仍在符号模式。保留活动组标识、分隔条拖动和面板本身的关闭操作。 |
| 第一批 | 顶栏与资源树重复的工程切换、搜索；顶栏与状态栏重复的服务入口；多处保存状态 | 全局入口去重，撤下独立工程上下文行 | 顶栏保留工程选择、统一查找、NC 服务；移除代码上下文行和树上的重复搜索按钮，以及树菜单重复的更换/最近工作区。模块信息纳入路径面包屑，编译按钮显示或提示具体模块；保存状态以标签未保存标记为主。树名称过滤继续保留。直接腾出一整行。 |
| 第三批，可选 | 底部编译输出、NC 服务、调试 | 「运行」面板内的三个子视图 | 默认底部标签从五个变为「问题、改动、运行」三个。运行内部切换编译、服务、调试，允许把常用子视图固定为独立标签。增加一次子视图切换，因此放在后续实施。 |
| 第三批，可选 | 调用层级、类型层级 | 「代码关系」面板 | 共用当前符号上下文和定位方式，内部切换调用关系、继承关系。两种关系仍有各自视图。这两项目前已经收在次级工具中，收益较小。 |

## 第一批的执行入口边界

现有服务面板里的开发流程包含编译、投送、中间件、客户端及调试配置，与开发任务存在交集，但行为不完全相同。第一批先统一编译与已有开发任务的入口；服务启停和流程详情继续由服务界面承载。

后续若把开发流程也接入执行菜单，应显示具体流程名称和步骤，调用现有执行逻辑，不能把不同流程强行当成同一任务。主按钮不随最近任务变成投送或重启；未保存确认、投送与重启保护继续保留。

## 结构与改动合并的必要条件

### 结构进入顶部符号模式

目前结构面板有本地解析兜底和 NC 声明支持，而顶部符号模式主要依赖磁盘 Java 文件和已就绪的代码智能服务。迁移前需要补齐：

- 当前未保存内容的结构与准确定位。
- 代码智能未启动、索引中或失败时的本地解析兜底。
- 当前已支持的 Java 与 NC 声明文件；保留仅方法过滤。
- 固定结构侧栏、随光标定位及从侧栏返回编辑器。
- 分屏时使用活动组的文件，关闭浮层后恢复原焦点。

不能先移除结构面板，再让用户等待后续能力补齐。

### 本地历史进入改动面板

现有改动面板已经合并时间线、比较与审查。本轮新增的是单文件本地历史的接入，以及路径行工具的收敛。

- 以「当前文件 / 工作区」区分范围，以「本地版本 / 本轮改动 / SVN」明确来源。
- 本地版本仍能独立浏览、比较和恢复，不依赖当前审查轮次是否有归档点。
- 切换文件或面板后保留选择、比较范围和滚动位置。
- 恢复前保留未保存保护，写盘期间保留操作锁定。
- 改动面板可与代码同时显示；当前行的改动标记继续留在编辑器。

## 推荐最终布局

| 区域 | 常驻内容 |
| --- | --- |
| 全局顶栏 | 工程选择、统一查找浮层、NC 服务状态入口 |
| 文件标签行 | 文件标签及未保存标记、编译当前模块 ▾、布局 ▾ |
| 路径导航行 | 后退/前进、跳转记录、模块与文件/符号路径、按需出现的改动摘要 |
| 编辑器 | 代码；结构等侧栏由用户按需固定 |
| 底部面板，前两批 | 保留现有问题、改动、编译输出、NC 服务、调试 |
| 底部面板，第三批可选 | 问题、改动、运行；支持固定编译输出或调试 |
| 状态栏 | 光标/编码等已有文件菜单、必要运行状态与异常提示 |

正常服务状态只保留一个主入口；代码智能故障、编码风险、调试暂停、任务失败等仍需主动显露，并提供恢复或定位操作。面板显隐可用布局菜单和快捷键控制；运行异常不能依赖用户自行展开菜单才发现。

## 不建议合并的功能

- **跳转记录与本地历史**：前者回到看过的位置，后者比较或恢复文件版本，分别留在导航与改动界面。
- **树名称过滤与工程全文搜索**：前者缩小当前树，后者查代码内容；资源树继续有过滤入口。
- **代码智能与 NC 服务**：两者运行状态和恢复操作不同，不能共用一个含糊的就绪状态。
- **问题列表与原始日志**：可以共用诊断展示，并按来源/构建批次筛选；原始日志仍需可查看。

## 分批实施与验收

1. **第一批：编译入口合并、布局菜单、全局入口去重、上下文行收敛。** 验收：代码上方减少一整行；当前模块编译仍一键可达且目标明确；工程切换和搜索快捷键保留；分屏、窄窗口和高缩放可用；异常状态与原有确认不退化。
2. **第二批：结构进入符号、本地历史进入改动。** 验收：未保存 Java、NC 声明及代码智能未就绪场景仍能查看结构；固定侧栏可用；历史比较与恢复正常；焦点、滚动、审查范围和文件选择能够恢复。
3. **第三批：按使用频率决定运行与代码关系面板是否整合。** 验收：运行标签正确反映构建/服务/调试状态；构建失败和调试暂停主动显露；日志不丢失；调试工具持续可达；常用视图可以固定，避免增加高频操作成本。
