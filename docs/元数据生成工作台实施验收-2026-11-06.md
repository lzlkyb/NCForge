## 已完成的流程

**已保存 BMF → 配置草稿 → 更新产物 → 检查差异 → 确认写入 → 查看结果与执行脚本。**

| 环节 | 实际行为 |
| --- | --- |
| 工作区 | 宽屏使用产物清单、内容预览与配置三栏；窄窗口使用配置抽屉，再窄时切换清单与预览，底部主操作保持可见 |
| 配置与导航 | 配置统一更新，目录检查防抖；搜索、状态筛选、分组选择与键盘操作可用；每份 BMF 保存自己的配置、选择和活动文件 |
| 内容检查 | 使用 Monaco 查看真实内容和文本差异，显示编码、换行及最终路径；来源和依赖可定位回元数据对象 |
| 写入保护 | 源 BMF、完整配置、目标真实路径与原始字节 SHA 绑定预览；空选择零写入；旧授权在目标变化后撤销，手改文件按逐项授权覆盖并备份 |
| 实际结果 | 逐文件报告新建、替换、保留及失败；部分失败仍保留成功项；清单只推进成功项的基线，并独立报告清单保存错误 |
| SQL 后续动作 | 独立执行弹层使用打开时的脚本快照；执行中阻止关闭，切到后台保留会话，组件真正卸载后停止后续语句；沿用测试库限制与执行确认 |

生成器继续提供现有 Java、SQL 和注册建议清单能力。预览主 BMF 只读取一次、构建一次计划；切文件、搜索和勾选复用有效预览。
