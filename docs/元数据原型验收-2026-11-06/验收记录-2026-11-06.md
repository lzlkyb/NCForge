# 元数据编辑工作台原型验收

方案与原型创建于 2026-11-05，验收完成于 2026-11-06。本记录验证独立 HTML 的界面与示例交互，不代表正式元数据功能已实施。

原型：[元数据编辑工作台](../../design/元数据编辑工作台-交互原型-2026-11-05.html)。方案：[升级方案](../元数据编辑工作台升级方案-2026-11-05.md)。数据：[交互与布局检查](交互与布局检查-2026-11-06.json)。

## 检查结果

10 组轻量 JSDOM 检查通过：初始选中、跨实体联动、空筛选与选中保留、非法名称/重复名称/长度校验、新建字段、未应用输入保护、文档草稿保留、撤销与模拟保存、接口/问题定位、键盘操作与文本转义。脚本运行无错误，最后一次 Node 堆使用约 48MiB；该值仅属于检查脚本，不是产品内存占用。

使用已打开的应用内浏览器、同一标签验证以下 9 组视口与主题，未启动额外 headless 浏览器进程：

| 视口 / 主题 | 结果 |
| --- | --- |
| 1600×900 浅色、深色 | 资源树、模型+字段、检查器同时显示，编辑按钮高度 30px |
| 1280×900 浅色 | 保留资源树，检查器默认收起 |
| 1024×768 浅色 | 资源树与检查器默认收起，中间保留联动区 |
| 1024×540 浅色 | 字段优先，字段内容区约 230px 高 |
| 819×614 浅色 | 字段优先，字段内容区约 304px 高 |
| 683×512 浅色 | 字段优先，字段内容区约 202px 高 |
| 560×900 浅色、深色 | 字段优先，字段内容区约 590px 高，辅助区域按需抽屉 |

所有组合均无窗口外部横向溢出；字段表内部可横向滚动。819×614、683×512 为可用空间等效检查，未进行真实 Windows DPI 测量。

浏览器实测通过：图/表/检查器选中一致、检查器编辑、应用草稿、预览后模拟保存、接口映射反向定位、键盘移动节点、资源与检查器抽屉、抽屉焦点循环与返回、窄窗口新建字段/差异弹窗、撤销新建字段。页面控制台无错误。

主题文字配色抽检：浅色最小对比度 4.80:1，深色最小对比度 6.82:1。覆盖正文、次要文字、选中项、警告与主按钮。

## 本轮修整

- 将大纲区域专用样式与轮廓按钮样式分离，修复编辑按钮被拉高及窄窗口隐藏的问题。
- 补充图标状态下校验按钮的可访问名称。
- 保护尚未应用的输入，避免切对象时丢失；筛选结果保留键盘入口。
- 补充辅助抽屉的焦点循环与关闭后返回。
- 默认画布缩放设可读性下限，容纳不下时在画布内滚动。

验收结束恢复浏览器默认视口、浅色主题与初始示例状态，保留预览标签。
