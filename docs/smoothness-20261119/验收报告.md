# NCForge 流畅性优化验收 — 2026-11-19

本轮覆盖文件标签、左侧工具页面切换、资源树、代码诊断、编辑器配置、面板及分屏拖拽，并检查数据库结果和服务日志滚动。改动已落到源码并通过前端生产构建，尚未发布或替换当前 Windows 安装版。

## 测量方法

Windows 上运行打包后的前端资源，使用 Microsoft Edge 157.0.4341.60，1440×900，遵守应用原有 CSP。文件、SVN、数据库和服务返回值由内存模拟，未写入用户工程或连接真实数据库。数据规模为 3,000 个树文件、30 个打开标签、每份 Java 源码约 1,600 行。

旧版对照在 `target/smoothness-before/desktop` 隔离构建，仅还原本轮修改的生产文件，其余工作区改动保留。前后使用同一脚本、同一浏览器版本、同一数据。采样时没有同时运行本任务的构建或单元测试。耗时从界面内触发操作到提交后的绘制机会计算；数值会随当前机器负载变化。

文件切换 90 次、页面往返 60 次。首次访问和冷加载由独立页面验收覆盖，未混入缓存切换指标。以下为最终单轮结果，早期并行测试时的临时数字不用于对照结论。

## 核心结果

表中延迟为 p50 / p95，长任务指界面线程超过 50ms 的任务数。

| 场景 | 优化前 | 优化后 | 长任务 |
|---|---|---|---|
| 已缓存文件切换 | 104.9 / 115.0 ms | 50.7 / 61.0 ms | 90 → 0 |
| 已访问页面往返 | 29.8 / 104.9 ms | 26.6 / 100.1 ms | 11 → 1 |

- 输入回显：持续 20 键/秒，29 个字符，p50 25.2ms，p95 29.3ms，最大 43.4ms。
- 编辑器布局菜单：10 次，p50 15.4ms，p95 27.2ms。
- 缓存文件切换期间没有新增文件读取请求。
- 60 次页面往返前后，DOM 节点 34904 → 34904，监听器 5437 → 5437；GC 后 JS 堆约 48.3 → 49.7 MiB。这是短周期稳定性检查，未替代数小时真实工程运行测试。

## 已实施

1. 差异计算转到 Worker，按模型版本及基线缓存；切文件或关闭视图会终止旧计算，旧结果不能覆盖新模型。恢复改动仍在执行前核对当前文本。
2. 活动文件高亮只通知原行和新行，树结构和回调引用稳定，切标签无需遍历重建整棵树。
3. 问题徽标按实际内容复用。文件首次变为未保存时，未变化的徽标不会带动整棵树刷新；真实诊断和编译失效状态仍能更新。
4. 诊断按文件索引，无关文件的诊断广播不重建当前行尾提示。诊断面板和编码标记缩小订阅范围。
5. 编辑器偏好相同时复用配置，避免每切文件重复更新；保留模型晚到、语言变化及大文件降级行为。
6. 文件会话元素在工具页面之间保持稳定。代码与文档面共享固定尺寸区域，非活动面停止显示并设为 inert，保留编辑现场。
7. 相同布局更新不再广播；侧栏、底部面板和编辑器分屏的拖拽合并到每帧一次，松手时保留最终位置，卸载时取消过期帧。
8. 宽表格复用未变化的列窗口，减少行级重复绘制裁剪；保留冻结列、编辑、选区和键盘导航。

## 滚动压力场景

结果网格实际加载 4,035 行、100 列，服务日志实际加载 4,000 行。脚本连续横向、纵向、斜向推进滚动位置；网格保持可视窗口渲染（本轮终态 21 行、14 个表头），没有缺失的可见单元格。

| 场景 | 帧间隔 p50 | 帧间隔 p95 | 长任务 | 空白检测 |
|---|---|---|---|---|
| wide-grid-horizontal | 10.0 ms | 20.1 ms | 0 | 0 |
| wide-grid-vertical | 19.9 ms | 20.1 ms | 0 | 0 |
| wide-grid-diagonal | 20.1 ms | 40.0 ms | 0 | 0 |
| file-tree | 10.0 ms | 20.0 ms | 0 | 0 |
| service-log | 10.0 ms | 10.1 ms | 0 | 0 |

极宽结果表高速斜向滚动仍有 40ms 慢帧，尚不能宣称该压力场景持续达到 55fps。资源树和日志的常规滚动较稳定。上述滚动数字来自独立压力回放，不与缓存切换样本合并。

```powershell

node scripts/smoothness-acceptance.mjs after
$env:NCFORGE_PERF_ARTIFACTS='../../docs/smoothness-20261119/page-switch/'
node scripts/page-switch-acceptance.mjs after
```
