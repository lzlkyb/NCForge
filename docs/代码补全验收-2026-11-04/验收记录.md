# Java 代码补全实施与验收

> 本文保留补全专项的阶段记录。后续 jar 缓存失效、Monaco 生命周期修复、最新测量及完整门禁结果见[工作区改动审查与提交验收](../工作区改动审查与提交验收-2026-11-04.md)，提交验收以该记录为准。

日期：2026-11-04。目标：修复类名前缀不自动弹出候选，恢复可靠的 Java 语义补全，并以本机 Eclipse 作为可重复的核心能力基线。

## 验收结论

当前 JDT 与本机 Eclipse 在同一组 19 个目标候选场景中均为 19/19 命中。真实 Monaco 的 12 项交互检查通过，并确认没有未处理页面异常。Java 补全专项及关联前端回归 74 项通过，依赖补丁专项 2 项通过。真实 JDT 测试通过。

这证明已覆盖所测核心工作流，不能据此宣称全面超越 Eclipse 或达到行业顶尖。未比较 Eclipse UI 排序、第三方助手、所有业务工程以及所有 Java 语法位置；首次分析与详情解析也仍有数百毫秒开销。完整仓库的 Rust 格式和严格 Clippy 门禁有与本轮补全无关的既有阻挡，详见下文。

## 已实施的能力

- 普通字符自动触发：100ms 输入防抖，类名前缀、点号成员、注解等走真实 JDT 补全。
- didOpen/didChange 串行同步；补全前等待文档同步。关闭后立即重开相同路径不会发生通知乱序，同步失败可以重试。
- 保留方法重载、构造器、泛型、链式调用、继承方法、工程类、静态方法、包名与同名类区分；接受方法/构造器后打开参数提示，参数占位符可继续编辑。
- resolve 处理真实导入、文档、替换/插入范围与废弃标记；快速回车、继续输入、切文件、服务重启使旧编辑失效，避免导入写入错误文件。
- 满额候选列表标记 incomplete，继续输入时重新查询；模板只参与匹配前缀，避免挡住文档单词候选。
- 2000 行阈值只降低编辑器显示成本，不再关闭语义补全；6500 行有效源码已实测。
- 全 NC 类名目录扫描本机 4382 个 jar，缓存中央目录，修改后的 jar 更新缓存；只展示普通公共顶层类，保留 NC 同名类覆盖优先级。
- 大写类名前缀至少两个字符时补充全库发现，每批最多 30 项。成员位置仍交给 JDT。加载停止时目录构建可取消，不保存半份缓存。
- 选择全库类后，按 NC 顺序加入目标 jar 及父类/接口依赖，再由 JDT 计算安全导入。两个同时解析的类型不会相互覆盖。
- 类路径写入只允许生成的影子工程。Rust 校验真实模块文件路径与受控索引，Java 扩展再次核对 canonical projectRoot；客户端不能直接传任意 jar。
- 首次按需加载期间立即接受候选，保留有效的全限定类名；解析完成后接受使用简名与 import。此行为保证未完成加载时插入仍有效。
- Monaco 0.52.2 同词高亮有两个未处理 Delayer 拒绝；通过有版本和源匹配检查的安装/启动补丁在源头处理，使用 Monaco 既有错误处理器忽略正常取消并保留真实错误上报。

## 复现命令

在 `desktop` 目录执行，先确保重任务没有并行运行。需要设置以下 PowerShell 环境变量：

```powershell
$env:CARGO_BUILD_JOBS='1'
$env:NCFORGE_JAVA_HOME='D:/ncc/1909home/ufjdk'
$env:NCFORGE_JDTLS_DIR='D:/AItool/aiwork/nc-workbench-m0/jdtls/ls'
$env:NCFORGE_NC_HOME='D:/ncc/1909home'
$env:NCFORGE_CLASS_CACHE='C:/Users/19145/AppData/Roaming/com.aier.ncforge/class-index.bin'
$env:NCFORGE_JDTLS_EXT=(Join-Path (Get-Location) 'src-tauri/resources/jdtls-ext/ncforge-jdt-ext.jar')
$env:NCFORGE_TYPE_CATALOG_CACHE=(Join-Path (Get-Location) '.cache/type-names-live.json')
$env:NCFORGE_COMPLETION_REPORT=(Join-Path (Get-Location) '.cache/java-completion-after.json')
New-Item -ItemType Directory -Path '.cache' -Force | Out-Null
node scripts/build-jdtls-ext.mjs
node scripts/rust-gate.mjs test --no-default-features --test java_completion_live -- --ignored --nocapture
$env:NCFORGE_ECLIPSE_HOME='D:/tool/eclipsehy'
node scripts/eclipse-completion-baseline.mjs
```

Eclipse 探针使用独立临时安装/config/workspace，原装 bundle 使用绝对位置，第三方更新器与助手不启动，结束清理临时目录，不修改用户 Eclipse 工程。
