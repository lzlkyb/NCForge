# 软件更新体验梳理

## 行业参考

- VS Code 的 Release highlights 与按领域组织的详细发布记录分层，提供版本历史导航：https://code.visualstudio.com/updates/v1_140
- IntelliJ IDEA 提供明确的更新入口、稍后与忽略选择、更新策略和升级后 What's New：https://www.jetbrains.com/help/idea/update.html
- 本项目沿用后台准备、先看说明、由用户选择重启的流程，不自动安装、不强制打开说明。

## 发现与修复

1. 亮点在模型截到四条、界面再截到三条；0.3.0 原来只有一句综合摘要。补八项已有功能的用户导读，移除双重截断。
2. 短摘要覆盖同版本元数据完整分类。按字段合并：远端非空分类优先，空分类从同版本历史补齐。
3. 完整记录藏在多层折叠中。改为亮点与完整记录两个视图，记录支持关键词搜索；切换版本重置视图，下载进度变化保留搜索与视图。
4. 左侧装饰占据阅读宽度。压窄品牌区、增加内容宽度，操作固定底部，长文只在内容区滚动，窄窗口转换纵向布局。
5. 下载100%不等于验签完成。徽章与折叠导航统一显示校验中，收到后端 ready 后才显示更新就绪。
6. 安装失败保留包时原来仍展示绿色就绪。改为安装重试，详情明确未完成，按钮为重试安装并重启。
7. 保留非打断式就绪提示、安装前保护和升级成功后的查看更新内容入口；不重复弹出更新详情。

## 0.2.0 → 0.3.0 导读

直接改数、网格操作、NC 热替换、连接迁移、代码搜索、首次查询、Oracle 稳定性、导入导出可靠性。内容来自 CHANGELOG.md 已记录功能，不新增功能承诺；完整分类记录保留原文。

## 发布与验收边界

CHANGELOG.md 为唯一内容源，需生成随包记录，并由发布脚本重新生成更新清单与内嵌历史。已发布的0.2.0客户端自身三条上限无法由服务端说明解除；新界面在升级后生效。未发布任何远端更新，未启动真实安装器。
