# 数据库查询复制与导出升级方案

建议采用「快捷复制 + 统一高级复制/导出窗口 + 可复用预设」。目标是把结果方便、准确地送到 Excel、SQL 编辑器、接口调试和文档中；范围、列、格式和目的地分别选择，避免每新增一种格式就扩充一排菜单。

本方案已核对当前源码，并于 2026-11-06 查阅 DBeaver、DataGrip、Navicat 官方文档。本轮只提供方案，未修改产品代码。竞品文档覆盖的版本、版本档次不同，功能列表不代表所有免费版都具备。

## 交互设计

### 快捷复制

`Ctrl+C` 保持复制选区；单个单元格复制原始完整值。单元格编辑或文本编辑焦点中的快捷键保留文本复制语义。

复制按钮使用分体入口：主按钮复制当前选区，没有选区时明确显示「复制当前结果」；箭头菜单提供 TSV、CSV、JSON、Markdown、INSERT、IN 条件及「高级复制…」。菜单顶部显示例如「选区 12 行 × 3 列」，切换格式不会扩大范围。

单元格/列右键提供「复制原始值」「复制列名」「复制唯一值」「复制为 IN 条件」。IN/NOT IN 的 NULL 处理需要明确语义：默认跳过并提示；需要匹配空值时显式加入 `IS NULL`，NOT IN 的空值策略也单独处理。Oracle 大列表继续按兼容版本的 1000 项拆分；字符串引用与去重按类型执行。

记住常用格式及表头偏好，但不记住「全部重查」或自动扩大选择范围。

### 高级复制与导出共用窗口

入口是「高级复制…」和「导出…」，共用设置与预览，底部主按钮分别为「复制」或「保存文件」。

1. 范围：当前选区、当前筛选结果、已加载全部行、重新查询导出全部。当前选区默认选区列；其他范围默认可见列，可切换全部列或手动选择。
2. 列：显示名称、中文名称、类型，勾选并排序；提供数据库列名/中文名/双行表头选项。JSON 键与 SQL 标识符继续使用有效的技术名称。
3. 格式：常用格式选择，相关选项才展开；编码、分隔符等复杂设置归入「高级」。
4. 预览：前 10 条已选记录，按实际输出文本展示；SQL/JSON 可高亮，长值限制预览长度并标记，实际输出不沿用预览截断。
5. 输出：文件名、保存位置、当前设置摘要；复制展示行列数与估算大小，文件导出提供原生保存对话框。

预览只使用已加载样本。全部重查的预览明确写「当前结果样本，重新查询的数据可能变化」，不为预览执行全量取数。

窗口沿用数据库双主题视觉语言，浅深、玻璃实色都覆盖；内容内部滚动、底部操作固定。窗口宽度不足时上下排列，始终保留范围摘要、预览入口和主操作。

推荐预设：「贴到 Excel」「接口 JSON」「文档表格」「主键查询」「NC INSERT」。用户预设只保存格式和选项，不保存结果数据、口令或隐式重查权限。

## 数据口径与保真

- **当前结果与重查分开。** 当前结果保持本地筛选、排序和已选列；已加载全部行可以忽略本地筛选，但要明确显示。重查使用来源 SQL，明确独立会话、执行时间及 200 万行上限；它看不到其他会话的未提交事务。当前结果若含未保存编辑值，在摘要标明，可切换查询原始值。
- **多结果集来源固定。** 操作绑定结果 ID 与来源连接，切换标签不会改变已开始的任务。隐式结果集及可能产生写入的过程语句只允许导出已取结果，不为导出重放过程；全部重查仅对经过现有只读取数校验的查询开放。
- **本地筛选不会自动改 SQL。** 从本地筛选切到全部重查时说明该筛选不适用；要取数据库侧筛选结果，先形成明确的服务端查询。
- **NULL 与空字符串可区分。** CSV/TSV 提供空白或指定 NULL 文本；JSON 使用 `null`，SQL 使用 `NULL`。文本交换预设允许使用 `\N` 等可识别标记，预览展示实际效果。
- **数字与编码不变形。** Excel 中长主键、前导零代码、超出 Excel 精度的数值按文本写入。JSON 的大整数和高精度小数采用明确的字符串策略，不先转成 JS number；必要时检查 JDBC/Rust/IPC 链路，已在上游丢失的精度无法由导出恢复。
- **时间格式按类型。** 区分 DATE、TIMESTAMP、时区和小数秒，SQL 字面量复用后端类型规则；普通 JSON 默认不把本地时间擅自转换为 UTC。
- **TSV 行内字符策略统一。** Excel 粘贴模式保留被引用的换行、制表符；简化纯文本模式可以压成空格，但不能无提示地替换原值。CSV 引用、转义、BOM、LF/CRLF 可预览。
- **重复列名不覆盖。** JSON 对象模式遇重名时提供明确且可预览的唯一键映射；要求无歧义保真时可选 `{columns, rows}` 结构。不得用重复对象键悄悄丢列。
- **SQL 生成需要表和键。** 联表、表达式结果不能仅靠正则猜表名就宣称脚本可用；INSERT 要核对目标表和列映射。UPDATE 要有唯一键和原值条件，NULL 用 `IS NULL`，缺键时禁用；生成和复制脚本不执行脚本，默认不追加自动提交。
- **NC 规则显式。** 多语列置 `~`、丢弃语种列、二进制写 NULL 属于迁移转换，展示将被改写/跳过的字段并列入完成摘要，通用导出不默认套用。
- **长文本与二进制完整性。** 记录源值截断、跳过、转换数量，区分预览截断与取数截断。完整模式不能把显示用截断文本当原数据导出；大对象处理需跟读取协议一起验证。
- **表格公式处理。** 保留当前公式注入防护；XLSX 对字符串显式写文本单元格。面向机器交换的 CSV 如允许原始文本，需在格式选项中明确与「贴 Excel」预设的区别，不能静默改变字符串。

## 等待、进度与完成反馈

导出进入现有任务中心，阶段为「准备查询 → 读取并写入 → 完成文件」。显示已写行数、字节数、已用时间、行/秒及写入字节/秒；这是导出吞吐，名称使用「写入速度」。

已加载数据有准确总量，可显示进度百分比；数据库重查未知总量时显示不定进度条。需要精确计数时可另行提供用户选择的计数操作，并说明额外查询成本；计数若不与导出共享一致快照，须标为估计总量。不能按猜测给出稳定的百分比和剩余时间。

耗时复制显示「正在生成…」，完成提示「已复制 12 行 × 3 列 · JSON」。剪贴板操作失败保留设置与预览，提供保存文件。大复制量先估算大小；首版建议超过 5 MiB 提示改为文件，具体限制经过本机剪贴板验证后定稿。

取消先显示「正在停止…」，收到后端结果后结束。继续使用导出实例 ID 防止串任务；查询期间取消的响应边界要在 UI 说明并测试。

完成显示实际路径、行列数、文件大小、用时与完整性，提供「打开文件」「打开所在文件夹」「复制路径」「再次导出」。失败展示可操作原因，如磁盘空间不足、路径不可写、断线或取数超时；保留当前选项重试。

部分文件必须标为「已停止，部分结果」，不能显示完整成功。JSON 数组要正确闭合，XLSX 要完成封装后才可称为可打开的部分文件；无法完成封装的临时文件按既有原子写入契约清理或明确标为未完成。取消与失败不覆盖上一份完整文件，保留部分输出使用不同文件名。

## 实施与性能

前端沿用结果网格选择、列布局和任务中心。小复制在共享序列化函数中处理，新增高级窗口拆为范围/列、格式/预览和输出三块；ResultGrid 不承接导出状态，组件仍遵守 300 行体量门禁。

复制与文件导出共享可验证的选项契约。Rust 继续做查询流式取数与原子落盘；前后端格式函数保持同一组测试样本，防止 NULL、日期和引用规则不同。多格式通过有限的格式分派实现，不引入任意脚本执行系统。

XLSX 优先评估后端逐行写入实现，核对依赖体积和真实内存增长，再确定实现库；不把全部结果送进前端组装工作簿。每张表最多 1,048,576 行，含一行表头时数据容量为 1,048,575 行，超出按工作表或文件拆分并明确提示。多结果集可分工作表；查询 SQL 与来源摘要作为可选说明页。

进度事件按页且节流输出，目标每秒 2–4 次；依赖事件订阅，不新增轮询。导出选项、连接来源和结果 ID 在开始时冻结，用户切页、重查或切连接不会改掉正在写的任务。

建议三批：

1. P0：范围口径、快捷/高级复制、CSV/TSV/JSON/Markdown/HTML、IN/WHERE 与 SQL 基础规则、原生保存与反馈。验收以「选区和输出一致、文本不损坏」为核心。
2. P1：XLSX、JSONL、共享流式导出配置、进度、取消、预设、多结果集、NC 迁移整合及带键 UPDATE。验收以「完整性、类型保真、大数据不卡界面」为核心。
3. P2：按实际使用频率补 XML、开发模板与压缩批量输出。每项独立评估体积和维护收益。

## 验收点

- 同一矩形选区在 TSV、CSV、JSON、Markdown、HTML 中保持同样行列，不因切格式而扩大到全部数据；显示列、隐藏列、列顺序、本地筛选、排序分别验证。
- Ctrl+C 在网格、单元格编辑和 SQL 编辑器的焦点语义正确；空数据、无选区、隐藏全部列、全 NULL 行提供明确状态。
- 中文、引号、反斜杠、换行、制表符、NULL、空串、公式前缀、前导零、20 位主键、高精度小数、日期与小数秒都有共享测试样本。
- 重复列名的 JSON 不丢字段；SQL 目标表映射、引号、唯一键、NULL 条件、Oracle IN 分组和 NC 转换告警验证。
- 重查与屏幕快照的区别、未提交修改、多结果集、不可重放过程语句、来源连接变更有回归测试。
- 10 万行普通导出、52 列宽结果、到达 200 万行限制、XLSX 工作表边界通过测试；大数量边界使用生成器与可注入限额，避免测试在系统盘制造巨量文件。
- 采样导出器额外内存和界面响应时间；流式内存随批次而非总行数增长。实际预算按数据宽度与格式测量后公布。
- 取消、重复点击、两任务进度隔离、断线、超时、文件占用、磁盘失败与原子写入都覆盖；完整文件不会被取消或失败覆盖。
- Excel/WPS 打开 XLSX 与 UTF-8 CSV，验证中文、前导零与精度；JSON/JSONL 可解析，SQL 用只读测试环境或语法样本验证。
- 浅深主题 × 玻璃实色 × 正常/低窗口：菜单可见、Tab 焦点顺序、Esc 返回、固定底栏、等待和错误状态通过生产 CSP 浏览器验收；剪贴板与原生保存另做桌面环境验证。
