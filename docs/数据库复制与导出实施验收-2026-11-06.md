# 数据库复制与导出实施验收

本轮按已确认的[升级方案](./数据库查询复制与导出升级方案-2026-11-06.md)和[交互稿说明](./数据库复制与导出交互稿说明-2026-11-06.md)实施 P0/P1。验收使用固定数据与模拟连接，不读取或修改真实业务库；没有构建 exe / 安装包、修改版本号或提交工作区。

## 已实现范围

| 使用场景 | 实施结果 |
| --- | --- |
| 快捷复制 | Ctrl+C 保留选区语义，单格复制完整原值；统一 TSV、CSV、JSON、Markdown、HTML、INSERT、单列 IN 入口 |
| 高级复制 / 文件导出 | 共用范围、格式、列选择与排序、表头、NULL 和预览；复制与文件分别记住最近格式和表头 |
| 数据范围 | 当前选区、当前筛选结果、已加载全部行、独立会话重新查询；原值与未保存修改明确区分 |
| 输出格式 | TSV、CSV、JSON、JSONL、Markdown、HTML、INSERT、IN / NOT IN / WHERE、有键约束的 UPDATE、XLSX |
| SQL 脚本 | UPDATE 要有已确认唯一键，定位使用原始键和原值条件；生成脚本不会执行 SQL |
| Excel | 原生 XLSX、多个结果集分别输出工作表，长主键和前导零保留文本，字符串不作为公式执行 |
| NC 迁移 | 保留独立取数、多语列转换、主键前置、提交间隔与上限；接入原生保存，并展示转换和截断告警 |
| 保存与任务 | 原生选择位置、实际文件名回填、阶段 / 行数 / 用时 / 速度；总量已知显示百分比，未知时不虚构进度 |
| 任务恢复 | 后台运行、停止、部分文件、失败重试、打开文件 / 所在目录 / 复制路径；切页卸载后仍可恢复原来源和设置 |
| 预设 | 内置常用输出及用户预设；持久化不保存业务数据、口令、SQL、定位键确认或重查权限 |
| 双主题 | 浅色 / 深色与玻璃 / 实色均接入，窗口实底、内容内部滚动、底部固定，窄屏提供预览跳转 |

大选区复制使用生产 Worker，超过 5 MiB 引导改为文件。预览最多取前 10 行，不为预览重新查库；预览文本截断不会改变实际输出。文件流式导出硬上限 200 万行，达到上限会标记部分结果。

## 数据准确性与任务边界

- JSON 重复列名生成稳定唯一键，也支持列数组 / 行数组结构；大整数、高精度数字保留字符串。
- CSV / TSV 保留引用内换行、制表符与 NULL 选项；HTML 写入 UTF-8 meta，并同时提供富文本与纯文本剪贴板内容。
- 全量取数使用冻结的源 SQL 和绑定参数，不使用带 RN__ 的分页包装 SQL；过程的隐式结果集只导出已加载数据，不重放过程。
- 多结果集 XLSX 使用各结果集原始全列和顺序，不沿用第一结果的选区字段。
- 保存目的地使用原生对话框授权 token；文件名或格式改变后清除旧 token，取消选择不读取数据库。
- 写入先生成临时文件，完成后原子落盘；停止或截断使用独立部分文件名，不覆盖已完成文件。
- 停止请求按实例隔离，迟到的停止失败不能复活完成任务或污染新任务。保留最近 5 个完成任务的内存重试快照与 30 条历史摘要，限制缓存增长。

## 本轮修复的交互问题

修复了玻璃主题窗口透底、成功 Toast 遮挡按钮、窄屏预览难到达、原生对话框改名后界面未回填、文件后台运行时打开复制窗口丢失控制器，以及切结果页后失败重试错误地使用新页面数据的问题。复制失败转文件会携带原列选择、格式、NULL、分隔符、转置和编辑值口径。最终复查还隔离了复制窗口与文件任务状态：文件停止或封装期间，复制操作保持可用。

### 体积预算

通过 Vite 内存源码覆盖做隔离对照：从当前 ResultTable / TableData 撤回本批导出接入，使用此前 RowsEntryView / NC 导出 / 格式工具实现，其它工作区模块和既有数据库视觉保持；正式 `dist` 未被对照构建覆盖。对照结果为本批增加 46,374 字节 raw / 15,674 字节 gzip，即 45.29 / 15.31 KiB，最大块没有增长。[体积对照数据](./数据库复制导出实施验收-2026-11-06/体积对照.json)记录覆盖模块哈希和前后各 chunk 大小。

预算只为本批增加 46 KB raw / 16 KB gzip，最大块保持 3171 KB；其它会话后来追加自身元数据增量，当前总预算为 5011 / 1435 KB，本批额度完整保留。最终混合工作区产物是 5027 / 1441 KB，仍超出总预算 16 / 6 KB；撤回本批功能的对照产物仍超出扣除本批增量后的预算，剩余增长来自其它工作区改动，需要其所属任务核对，未用自动更新预算掩盖。此项整体门禁未通过，不影响本批实测增量结论。

## 已知验证限制

全量 Rust 测试已完成所有目标编译，但 lib 测试进程在测试执行前以 `0xc0000139` 退出。项目已有记录：lib 测试目标缺少 Common-Controls v6 manifest，GUI 依赖导入 `TaskDialogIndirect` 失败。独立集成 harness 具备 manifest 并正常运行；本轮没有扩大范围修改构建脚本，不能将独立集成通过写成全量 Rust 测试通过。

未运行真实 Oracle 独立导出连接、系统保存 / 打开对话框或新安装包。独立查询会话看不到主会话未提交事务；源读取链路已丢失的精度或截断值，输出阶段无法恢复。XLSX 超过单格容量会明确拒绝写入，不静默截断。

本轮结论只对已验证范围成立，不代表软件没有任何 bug。真实数据库与新安装包端到端验收仍需在对应环境执行。
