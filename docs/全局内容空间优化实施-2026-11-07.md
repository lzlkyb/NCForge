# 全局内容空间优化实施

用户将本轮从 SVN 审查页扩大到其他同类页面，并明确后续不需要设计稿。以下直接修改真实组件；原有工作区改动保留，版本号不变。

## 实施范围

| 页面 | 空间调整 | 必要反馈与操作 |
|---|---|---|
| 代码审查 | 合并文件／阅读／差异导航工具条；取消重复页签与说明；加入专注对比 | 文件搜索切换、首处差异定位、返回恢复阅读状态；审查与提交选择独立 |
| SVN 历史 | 作者及日期按需筛选；提交说明和完整路径清单移入详情；当前路径使用单行选择器 | 历史范围、关键词、版本号、当前比较路径常驻；加载失败可重试 |
| 数据库 | 足够宽的控制台将连接上下文和执行工具条并为一行；窄窗口保持有序分行 | 连接、schema、环境、事务方式、只读控制及事务异常继续可见；生产环境标记保留 |
| 元数据 | 取消重复工具页签；合并组件标题、校验与工作模式；批量字段操作收进菜单 | 非零校验问题、编辑／草稿状态和保存入口保留；真实多文档标签保留 |
| 日志 | 取消重复工具页签；宽屏合并筛选与检索；普通检索统计不重复占行；记录属性按需展开 | 错误、过期、截断、达上限提示保留；原因与下一步始终可见；关闭入口迁入工具栏 |
| 补丁 | 输出目录与附加 SQL 收进打包设置；去除重复的返回审查按钮 | 阻断、删除文件、进度、取消、未保存提醒和生成按钮常驻；确认出包及保存目录校验保持原有流程 |
| 设置 | 取消与设置页自身导航和标题重复的固定工具页签 | 设置分组、搜索、表单标签和说明保持可达 |

共享规则位于 `desktop/src/content-first.css`，具体菜单仍由各组件管理。没有通过缩小代码字号、行距或点击区域换空间。代码编辑器真实文件标签、服务控制台启停／取消及设置分组具有实际操作意义，不做统一隐藏。

## 已验证的实际空间

- 1920×1020 审查夹具：代码区域高 851.5px；专注模式高 852.5px、宽度从 1570px 增至 1854px。
- 1920×1020 数据库生产前端夹具：连接及执行栏合并后高 41px，无内部横向溢出。
- SVN 浏览器测试覆盖 12 种窗口、主题及密度组合，以及历史、追溯、冲突、提交草稿与冲突排除；额外检查补丁目录草稿、日志与窄窗设置。
- 元数据生产前端夹具的 14 种窗口／主题组合，包含 1024×540、683×512、560×900，均保留可用字段区域且没有页面横向／纵向溢出。

## 回归与限制

- 分批相关单元测试共 44 个文件、170 项通过，涵盖元数据编辑／保存／非法粘贴、日志检索、事务、工作台、SVN 比较器及补丁目录草稿。新增 StrictMode 回归，防止预清理缓存空初始视图导致首次不定位差异。
- 组件体量、孤立依赖、命令契约、设计 token、UI 约定、ESLint、TypeScript、生产构建与包体预算门禁通过。
- 数据库生产产物实际运行 Worker，3000×80 数据保持虚拟化，并验证宽屏工具栏、选区、筛选和主动释放。
- 设计机械扫描没有新增命中。
- 元数据首次画布拖动样本主线程 P95 为 18.647ms，高于原有 16.7ms 门槛；原始结果保留为 `全局内容空间优化验收-2026-11-07/元数据/首次性能样本.json`，不降低测试阈值。
- 顺序复核完整元数据生产验收通过：拖动主线程 P95 15.101ms，热切换 P95 45ms；反复关闭后 JavaScript 堆增长约 113KB。首次超线样本仍保留，以记录该机器上性能测量的波动。

所有浏览器数据通过内存 Tauri IPC 夹具提供，不连接真实业务数据库或 SVN 仓库。未打包安装程序，未自动提交代码。
