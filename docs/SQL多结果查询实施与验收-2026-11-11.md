# SQL 多结果查询实施与验收

日期：2026-11-11。已按确认的设计落实生产代码。浏览器使用真实组件与前端状态机，数据库边界使用演示数据；真实 Oracle 尚未连库验收。

## 用户可见行为

- 保留一个较大的“执行”主按钮。无选区执行整个脚本，有选区执行选中 SQL；Ctrl+Enter 与主按钮一致。下拉菜单保留“执行当前语句”“执行整个脚本”和当前语句采集统计；Ctrl+Shift+Enter 仅执行光标处语句，Alt+X 执行整个脚本。
- 多条语句在同一会话依次执行，每条 SELECT 保留独立结果。默认标签查看，可按需切换双栏并替换任一栏的结果。第一份结果返回后显示第一份；后续结果完成不抢走正在查看的页。
- 每份结果独立筛选、排序、滚动、选区、复制、导出和续取。切到输出或其它结果再返回，已看过的结果保留本地状态。失败或停止保留已完成结果。
- 全选入口位于表格左上角、行号与列头的交界处。点击或在网格/表头按 Ctrl+A，选择当前筛选后的全部已加载行和显示列，不改变滚动位置，也不影响另一份结果。空结果禁用入口。
- Ctrl+C 复制选区。兼容 WebView 只发送原生 `copy` 事件的系统复制命令，沿用现有复制格式、大小限制与成功/失败反馈。
- SQL 编辑器、筛选框和单元格编辑框保留原生全选文字/复制行为。Ctrl+S 写回仅作用于焦点所属结果，避免双栏或保活结果同时写回。

“全选”的范围是当前筛选后的已加载数据；未续取的行不会自动查询或复制。

## 实现接线

| 层 | 实现 |
| --- | --- |
| 执行范围 | `SqlEditor`、`SqlToolbar`、`SqlConsole` 共用 auto/current/script 语义 |
| 批次与布局 | `dbActions.runStatements`、`dbResultLayout`、`ResultPanel`、`ResultPaneHeading` |
| 游标归属 | `dbResultCursors` 按 resultId 登记连接、会话与标签；`dbStore` 校验请求身份后写回 |
| 前端接口 | `dbApi.execResult`、`moreResult`、`closeResult` |
| Tauri 命令 | `db_exec_result`、`db_more_result`、`db_result_close`；已登记并生成命令契约 |
| Java 桥 | exec 第五个可选参数 resultId，more 第二个可选参数 resultId，closeResult 关闭指定结果 |
| Rust 引擎 | 独立结果游标；临时 JVM 回退结果的续取按明确路由返回对应会话 |
| 网格交互 | `allResultSelection`、`useResultGridNavigation`、`ResultGridHeader`；各结果使用独立单元格 ID |

Java 桥每个会话最多保留 32 个命名游标。关闭结果、重跑、关闭标签、释放会话、换连接或会话失效时释放归属；已完成、隐式结果集和内存预算截断的结果及时关闭游标。旧请求迟到时不写入新一轮结果。旧 exec/more 接口保留给表页使用。

SQL 工具栏其它控件沿用生产结构。双栏中的结果工具条按栏宽收拢辅助文字；1280×720 验收时每栏约 541 px，工具条约 37 px 高、保持单行，复制的行列计数可见。窄文档区域双栏上下排列。

## 浏览器交互验收

使用生产 `SqlConsole`、`ResultPanel`、真实前端 store 和演示 IPC：

1. 两条 SELECT 均返回独立结果，双栏同时可用。
2. 第一份续取由 20 行增至 40 行，第二份仍为 20 行，数据与状态独立。
3. 第一份筛选“智慧”后 Ctrl+A 得到 8 行×4 列，Ctrl+C 实际复制 8 行；第二份保持 20 行×3 列。
4. 左上角全选与 Ctrl+A 一致。最终全选第一份后，Ctrl+C 给出“已复制 20 行×4 列 · TSV”，剪贴板内容正确。
5. 切换输出再回结果，筛选文字和选区仍保留。
6. 第二条失败时第一份的行与续取入口仍可用，第二栏展示错误和 SQL 定位入口。
7. 第二条返回 0 行时保留列头与空状态，全选入口禁用。

浏览器首次发现 Ctrl+C 没有复制反馈。补接网格原生 `copy` 事件后现场验证成功，并增加结果复制/编辑框原生复制的回归用例。
