# NCForge 手工验收清单

> 2026-10-28 生成。自动测试（Rust 221 项 / 前端 200 项）覆盖不到的都在这里：要么需要真实 NC 环境、
> 真实 SVN 工作副本、真实 Oracle，要么需要人眼看布局。
>
> 一共 **9 组 94 项**（I 组代码智能为 2026-10-28 晚补充，I17~I22 为 M4e，I23~I26 为随安装包分发）。全做完约 130~150 分钟（不含等服务启动的等待）。

## 怎么用

1. 从上往下做。顺序是按「风险递增 + 依赖关系」排的，跳着做容易返工（比如补丁要等编译产物）。
2. 每项前面是复选框，做完打勾；失败的**不要打勾**，在旁边写一行 `实际 = ...`，需要截图就存临时目录。
3. 标 🟥 的会改真实数据、占端口或吃内存 —— 做之前确认这台机器上没别人在等 NC 服务。
4. 全部做完把这份文件发我，或者直接说「哪几项挂了」，我按编号修。

| 标记 | 含义 |
|---|---|
| 🟩 | 纯界面，随时可做，不影响别人 |
| 🟨 | 只读，但慢 / 起进程 / 连库 |
| 🟥 | 会改真实数据或占系统资源 |

**建议顺序**：A → B → C → D → E → F1 → G → F2

理由：F2（提交）是唯一会改远端仓库的，放在最后；G 起服务要占 80 端口和 4G 内存，排在 F2 前面先做掉、测完停掉。

## H. 已知未做（这些不用测，测了也没有）

不是 bug，是这轮有意没做的。想加的时候再说。

| 位置 | 缺什么 | 为什么没做 |
|---|---|---|
| 代码智能 | 索引进度只在状态栏显示文字，没有设计稿里的「蒙层 + 百分比」弹窗 | M4d 先接通功能，弹窗留待 I 组验收后再定要不要补 |
| 代码智能 | 每次更新都要下载包含 jdt.ls 的整个安装包（约 +50MB） | 应用内更新分发的是整包，没有增量；要省需单独做「代码智能组件包」按需下载 |
| 代码智能 | 打包进安装包的 jdt.ls 只裁掉其它平台的 6 个 jar | m2e / gradle / ant 等看着用不到，但 jdt.ls 核心包 Require-Bundle 依赖它们，删了会起不来 |
| 代码智能 | 切模块 = 重启 jdt.ls（约 40 秒），不在原进程里换 classpath | 原进程换 classpath 未验证，先用已验证的做法 |
| 代码智能 | 只读标签页（jar 内类）里没有补全/悬停/跳转 | 请求只发给当前模块的真实文件，虚拟文档暂不同步 |
| 代码智能 | 轻量模式跳转只认工作区内的类名，不认 jar 内的类、方法、变量 | 不自建源码索引，用全文搜索找声明行，起步最轻 |
