# 全局选择态实施验收

本批在用户确认 HTML 对照稿后，将选择态规范迁移到产品组件。源码盘点清单包含 143 个文件、427 处选择或焦点标记；这些命中不是 427 个缺陷，不对执行状态、错误状态或不可见命中区域批量染色。

## 已落地

| 范围 | 产品行为 |
|---|---|
| 普通输入及组合搜索 | 统一焦点色；组合搜索由圆角容器承担焦点边界，消除内部矩形与双层描边；错误边框保留 |
| Schema 选择 | 搜索与清除、当前项勾选、方向键及 Home/End 定位、Enter 应用、Escape 关闭；应用或关闭后恢复触发器焦点，输入法确认不误提交 |
| 数据库结果网格 | 范围连续底色、仅逻辑外周 1px 边界、活动格聚焦 2px／失焦 1px；失焦底色降为中性；行列标题提示范围 |
| 网格特殊状态 | 冻结列使用同一选区底色；虚拟视口裁切不制造假外框；修改值保留警示底色和角标，错误保留警示色及波浪线，NULL 保留原有文本语义 |
| 树、列表及诊断 | 文件树、数据库对象、版本控制、补丁、日志、调试、问题与搜索结果使用共同选择色；已验证容器的树多选保留中性失焦态 |
| 导航、标签及设置 | 活动入口与分段项使用浅底色；编辑标签保留简洁底部标记；移除叠加的选中阴影，保持原有标题字重与信息层级 |
| 菜单及元数据 | 弹出层候选与当前项统一；字段、生成产物及历史项使用统一状态；画布仅对真实节点和关系着色，不改变命中区域 |

样式集中在 `desktop/src/selection-states.css`，选择几何集中在 `desktop/src/lib/gridSelection.ts`。保持原有选择逻辑、表格虚拟化和密度几何，不增加逐帧动画或后台任务。

## 验证与证据

- 定向单元测试：8 个文件、37 项全部通过，覆盖范围边界、虚拟视口、冻结列、密度切换、编辑取消、菜单、组合搜索、Schema 键盘选择与焦点恢复，以及元数据编辑和生成流程回归。
- 工程门禁：组件体量、孤立文件与依赖、Tauri 命令契约、设计 token、UI 约定、ESLint、TypeScript、前端生产构建及包体预算共 9 项全部通过。
- 生产前端浏览器检查：使用真实构建产物和 Worker，Tauri 数据接口以固定夹具模拟；3000 行 × 80 列网格验证有界 DOM、横向虚拟滚动、筛选、释放结果，以及 6 × 6 连续选区。
- 选择态检查覆盖浅／深色、实色／玻璃、标准／舒适密度共 8 种组合，以及强制颜色和减少动态效果模式；检查内部无粗框、外周 1px、活动格聚焦 2px，搜索框由父容器统一绘制边界。
- 浅深色截图已人工查看；搜索框截图及计算样式结果保存在 `docs/选择态实施验收-2026-11-07/`。
- Impeccable 机械检查：新选择态无命中；数据库 CSS 中另有两处既有进度条 `width` 动画警告，位于本次未修改的值反查及同步进度规则。

检查覆盖本批修改的交互及通用样式入口，不代表已逐屏人工验证清单中的所有组件；浏览器夹具检查不等同于真实数据库端到端测试。没有构建安装包，也没有重新运行与本批纯前端修改无关的 Rust 测试。
