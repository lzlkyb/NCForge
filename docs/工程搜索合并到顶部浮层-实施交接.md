# NCForge 工程搜索合并到顶部浮层

## 任务与当前状态

用户已确认把代码区的「工程搜索」合并到顶部「转到文件、类型、命令…」浮层。**首版功能已实施，搜索专项与浏览器验收通过**，已交付统一入口、完整工程搜索能力和返回位置恢复。结果固定到侧栏留待后续。基于已有未提交改动实施，保留其他任务的工作；未提交、未改版本号、未生成安装包。

当前实现、验收证据与全量门禁限制见 [工程搜索顶部浮层实施与验收-2026-11-14.md](工程搜索顶部浮层实施与验收-2026-11-14.md)。下文保留已确认方案及实施注意事项。

## 用户可见行为

- 顶栏点击仍默认打开「文件」模式。在「文件」旁增加「工程搜索」，共用原浮层的输入框、模式栏和焦点管理。
- 代码区的放大镜、「工程搜索」按钮、命令面板中的「全工程搜索」、`Ctrl+K`、当前键位方案和用户自定义快捷键，都打开浮层的「工程搜索」。覆盖浮层已打开和编辑器有焦点两种情况。当前文件内的 `Ctrl+F` 继续走编辑器。
- 在文件模式输入或粘贴 `#关键词`，切入「工程搜索」并填入关键词。回车或点「搜索」执行。默认按现有工程搜索范围，保留当前工程、全部关联工程、按组件三种选项。
- 输入框下常显范围、大小写、整词和正则。文件掩码与替换收进「更多」。保留搜索历史、JAR 符号与源码注释、源码预览、编辑匹配、搜索进度与错误反馈。
- 命中按工程、文件分组，显示行号、高亮片段和来源路径。边扫边显示可用结果，大列表继续虚拟化。方向键浏览，回车打开选中结果。搜索框中回车提交查询，向下键进入结果列表。关闭浮层后回到原焦点，打开命中则把焦点交给编辑器。
- 重新打开时恢复查询词、选项、结果、文件折叠状态和滚动位置。工作区切换后清理旧根所属的结果和位置，沿用现有的跨工程打开确认。

## 实施边界与风险

1. **合并查询路径。** 现有 [paletteSources.ts](../desktop/src/lib/paletteSources.ts) 的 `#` 走独立的 50 条快速内容搜索。浮层接入完整工程搜索后，清理这条重复路径及 [usePaletteSearch.ts](../desktop/src/hooks/usePaletteSearch.ts) 中专属的取消和防抖逻辑。文件名、类型、符号、命令和行号仍走各自已有流程。
2. **补齐流式结果和取消。** [search.ts](../desktop/src/lib/search.ts) 已有当前工程的 `searchWorkspaceStream`，支持未保存编辑覆盖、来源标识和取消。全部工程当前走 [search_cmds.rs](../desktop/src-tauri/src/commands/search_cmds.rs) 的 `search_projects`，一次返回最终结果，后端支持按来源取消，前端封装目前未透传。复用现有扫描和预算，给全部工程补分批发布，批次带工程根、工程名和本次请求标识。只接收当前请求的批次，最终结果以命令返回为准。搜索关闭、工作区切换或提交新查询时取消旧请求。已完成的结果保留供返回继续查看。
3. **核对未保存编辑。** 当前工程的调用已有覆盖逻辑。全部工程前端目前直接调用后端，若补齐覆盖，只给当前根应用未保存文本，防止同一相对路径的关联工程文件被覆盖。
4. **保护替换。** 继续限制在当前工程及当前工程的组件范围。只允许完整且仍匹配当前搜索条件的结果进入现有替换确认流程。测试改词、改范围、取消、分批未结束、换工作区等情形，JAR 命中始终走只读打开路径。
5. **处理焦点与重挂载。** 浮层当前用 `nonce` 重挂载模式正文，切模式时保留打开浮层前的焦点来源。焦点循环要覆盖下拉框和高级选项。已有 JAR 区块会在挂载时发请求，恢复同一份搜索时复用已返回的 JAR 结果。搜索结果与匹配计数沿用现有上限，避免分批显示时反复重建整份列表。

## 交付验收

- **入口与焦点**：顶栏、代码区按钮、`Ctrl+K`、Eclipse 的 `Ctrl+H`、IDEA 的 `Ctrl+Shift+F`、自定义绑定、`#` 粘贴及数据库引用跳转。检查 Tab 留在浮层、Esc 返回、输入法组词期间回车不误提交。
- **搜索与定位**：当前工程、全部关联工程、按组件、掩码、正则、未保存编辑及 JAR 命中。用两个工程中的同名文件确认来源显示和打开目标正确。打开命中后重开浮层，核对原查询、条件、折叠和滚动位置。
- **并发与规模**：模拟旧请求延迟返回、取消和切换工作区。验证分批出现结果且最终无重复。用万级命中验证 DOM 数量有界、键盘可到达远端结果、搜索和切换模式时界面可操作。
- **回归**：扩展 `QuickPalette.test.tsx`、`SearchTab.test.tsx`、`SearchResults.test.tsx`、`keymap.test.ts`，更新依赖旧搜索侧栏的测试。跑 TypeScript、前端专项测试及浏览器交互验收。若动 Rust，按项目规则用 `desktop/scripts/rust-gate.mjs` 跑搜索相关测试。
